# 電子カルテ情報共有サービス ドキュメントポータル

医療機関向け技術解説書・外部I/F仕様書を統合したインタラクティブHTMLポータルと、
PDF更新時のデータ再抽出スクリプトのセットです。

---

## ファイル構成

```
.
├── 電子カルテ情報共有サービス_技術解説書.html   # メインポータル（これをブラウザで開く）
├── extract_if_data.py                          # PDF → JSON/HTML 更新スクリプト
├── if_data.json                                # 抽出済みI/Fデータ（参照用）
└── README.md                                   # このファイル
```

---

## ポータルの主な機能

| 機能 | 説明 |
|------|------|
| 全文検索 | ヘッダーの検索バーでキーワード検索。技術解説書・I/F名・XMLタグ名すべてにヒット |
| カテゴリフィルター | サイドバーのタグ（FHIR・臨床情報・API・I/F仕様 など）で絞り込み |
| 章ナビゲーション | サイドバーから各章・各セクションに直接ジャンプ |
| I/Fフィルター | OQS / EPS / CIS / PMH ボタンで160件のI/F一覧を即時絞り込み |
| セクション折りたたみ | 見出しクリックで各章を開閉 |

## 新バージョンのPDFが届いたときの更新手順

### 前提
- Python 3.8 以上
- `pdftotext` コマンド（poppler-utils）が使えること
  - macOS: `brew install poppler`
  - Ubuntu: `sudo apt install poppler-utils`

### 手順

**① XMLレイアウト別紙のみ更新する場合**

```bash
python extract_if_data.py \
  --xml-layout 別紙3-1_XMLレイアウト_..._VerX_XX.pdf \
  --output if_data.json \
  --inject-html 電子カルテ情報共有サービス_技術解説書.html
```

実行すると：
- `if_data.json` に最新のI/Fデータを保存
- HTMLポータル内の `IF_DATA` 定数を自動置換

**② 技術解説書の本文を更新する場合**

HTMLの各セクション（section-body）を直接編集してください。
主な編集箇所は以下です：

```html
<!-- 第5章 臨床情報テーブルの保存期間を変更する例 -->
<td>登録日から5年間</td>  ← ここを編集
```

**③ 新しいI/F（例: CIS-IF-133）が追加された場合**

1. `extract_if_data.py` の `CIS_NAMES` 辞書に追記
2. スクリプトを再実行（上記①の手順）
