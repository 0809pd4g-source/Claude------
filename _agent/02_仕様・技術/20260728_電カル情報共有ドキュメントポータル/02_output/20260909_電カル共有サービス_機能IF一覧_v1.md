# 電子カルテ情報共有サービス 機能・外部IF一覧

出典：別紙1-1（Ver8.08）、別紙1-2（Ver5.03）、DVフラグPPT（R8年9月リリース時点）  
作成日：2026-09-09

凡例：
- IF ID の「/」は 要求/結果 のペア（例：CIS-IF-101/102 = 要求101・結果102）
- 「確認中」= 手元の仕様書に記載なし。マイナポータル連携仕様書等に定義される可能性あり
- ※1 = Ver7.02で削除済（配信マスタ変更に伴い不要に）
- ※2 = 閲覧保留廃止（技術解説書v2.1.0で「同意区分は同意ありのみ」に変更）

## 文書情報・閲覧保留系（#11〜#17）※2

## 「確認中」のIF_IDについて

以下の機能はマイナポータル連携仕様書・オン資端末向け仕様書等に定義されている可能性が高く、別紙1-1・別紙1-2では確認できない：
- マイナポータル経由の各種同意・閲覧機能（#13, #15, #26, #27, #29, #30, #38, #39, #41, #42, #48）
- オン資端末経由の同意系（#12, #16, #23, #24, #28, #35, #40）
- 閲覧保留系（#11〜#16）：廃止済みのため仕様書からも削除されている可能性あり
- 保険者向け（#43）
