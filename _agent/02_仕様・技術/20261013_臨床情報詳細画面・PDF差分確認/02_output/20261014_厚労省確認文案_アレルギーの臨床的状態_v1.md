# 厚労省確認文案：アレルギーの「臨床的状態」がPDFに出ない差の扱い

> 作成日: 2026-10-14
> プロジェクト: 20261013_臨床情報詳細画面・PDF差分確認
> 用途: 機構（内田さん、10/5）からの確認依頼「アレルギーの臨床的状態がPDFに出ない差を残してよいか」に回答する前に、厚労省の了解をとる。本田さんRv後に厚労省へ送る
> 関連: `20261014_PDFと詳細画面の差異_機構確認事項_v6.xlsx` の21・26行

## 1. 問題ないと判断した理由

### 何の差か

アレルギーの情報には「臨床的状態」（今もそのアレルギーがあるか：存続・治った など）という項目がある。

| | オン資端末の臨床情報詳細画面（自院が登録した情報を見る画面） | 臨床情報のPDF（他院が見る帳票） |
|---|---|---|
| 臨床的状態の欄 | **ある** | **ない** |

機構からは「この差は残す方針でよいか」と確認依頼が来ている（10/5開発課題検討会・内田さんの投稿）。

### 問題ないと判断した理由

1. **PDFには「今もある」アレルギーだけが載るため、欄がなくても読み違えない**
   技術解説書では、PDFのアレルギーは臨床的状態が「存続」のものだけを表示する決まりになっている。欄を作っても全行が「存続」になるだけなので、欄がなくても情報は欠けない。治ったアレルギーはそもそもPDFに載らない。
2. **画面では状態が見え、他院にどう見えるかも分かるようにする予定がある**
   画面には臨床的状態が表示される。さらに案件196（詳細画面のレイアウト変更、3月希望）で、「他の医療機関に表示されるのは『存続』のものだけ」という注釈を画面に出す予定になっている。登録した医療機関は、自院の画面で他院への見え方を確認できる。
3. **欄を足す改修をしなくても、医療機関の判断に影響がない**
   1・2により、PDFに欄を足す改修をする必要性は低い。

### 前提（機構に確認中）

上の判断は、次の2点が成り立つことが前提。機構への照会（Excel 21行）で確認する。

- **PDFが本当に「臨床的状態＝存続」で絞り込んでいること**
  2026年4〜5月の内部確認では、実装は臨床的状態ではなく「確からしさ」（確定・疑い・否定）で絞り込んでいるという説明があった。こちらが正しい場合、治ったアレルギーもPDFに載り、欄がないと治ったことが分からなくなる。その場合は判断を見直す。
- **PDFを読む人が「載っているのは今もあるものだけ」と分かること**
  PDF自体にその旨の注記があるかは未確認。注記がない場合は、技術解説書や周知で補う必要がある。

## 2. 厚労省への確認文（本田さんRv後に送付）

```
（厚労省ご担当者様）

お世話になっております。アクセンチュアの中澤です。
臨床情報詳細画面とPDFの差異（ToDo#1183の後続）について、DX機構への回答の前に1点ご確認させてください。

■ご確認いただきたいこと
アレルギーの「臨床的状態」（今もそのアレルギーがあるか：存続・治った等）が、オン資端末の詳細画面には表示され、PDFには表示されない差について、DX機構から「現状のまま残したい」との確認依頼が来ております。
ACNとしては、下記の理由から現状のままで問題ないと考えておりますが、この方針でDX機構へ回答してよろしいでしょうか。

■問題ないと考える理由
1. PDFには「存続」（今もある）のアレルギーだけが表示される決まりのため、欄がなくても読み違えは生じません（治ったアレルギーはPDFに載りません）。
2. 詳細画面では状態が表示され、さらに案件196（3月リリース予定）で「他の医療機関に表示されるのは存続のものだけ」と分かる注釈を画面に出す予定です。

■前提（DX機構に確認中）
・PDFが本当に「存続」で絞り込んでいるか（以前、別の条件で絞り込んでいるとの説明があったため確認しています）
・PDF上に「存続のものだけを載せている」旨の注記があるか
確認の結果、前提と異なる場合は、改めてご相談させていただきます。

お忙しいところ恐れ入りますが、ご確認のほどよろしくお願いいたします。
```

## 3. 機構への照会（Excel 21行の【確認】）の直し案

前提1を確かめるため、Excel v6の21行【確認】を次に差し替える（26行は「No.21と同じです」）。

```
【確認】PDFに出力するアレルギーの条件は、臨床的状態（clinicalStatus）が「存続（active）」のもの、確からしさ（verificationStatus：未確認・確認済み・否定）による制御のいずれでしょうか。以前の確認（2026年5月時点）では、verificationStatusで制御しているとのご説明があったと認識しております。あわせて、PDF上に「存続のもののみを表示している」旨の注記があるかをご教示いただけますでしょうか。
```

## やったこと・やっていないこと

- **やったこと**：技術解説書2.1.0版（PDFのアレルギーは存続のみ表示）・案件196（画面の注釈）・内部資料①（2026-04-16、実装はverificationStatusで制御）・10/5の内田さんの確認依頼をもとに、判断理由と厚労省への確認文を作成した。
- **やっていないこと**：PDFの実際の出力条件・注記の有無の確認（機構の回答待ち）。厚労省の宛先・送付経路の確認（本田さんに確認）。
