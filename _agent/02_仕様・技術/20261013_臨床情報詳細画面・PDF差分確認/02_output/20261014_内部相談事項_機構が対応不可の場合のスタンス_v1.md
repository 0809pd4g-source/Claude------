# 内部相談事項：機構が「対応できない」と回答した場合の厚労省のスタンス

> 作成日: 2026-10-14
> プロジェクト: 20261013_臨床情報詳細画面・PDF差分確認
> 相談先: 本田さん（ACN内部）
> 関連: ToDo#1183（10/5クローズ）→ 後続ToDo（#1228）、機構への照会（`20261014_PDFと詳細画面の差異_機構確認事項_v6.xlsx`・`20261014_機構返信文案_差異調査結果への確認_v1.md`）

## 結論・要点

1. 機構に照会している差のうち、「対応できない」と回答されうるものが**4つ**ある（名称の差、検査の「最新」、表示されるレコードの差、案件221で画面が対象外）。
2. 中澤の見立ては、**基本は「修正を求める」スタンス**。理由は、①厚労省はすでに案件213で傷病名について「画面をPDFと同じにする」方針を取っており、他の区分だけ差を認める理由がない ②全国展開が進むほど差が残る期間のリスクが大きくなる（10/5検討会での指摘）③医療機関の画面とPDFで同じ情報が違って見えることは、医療機関からの問い合わせ・誤認の原因になる。
3. ただし、**例外として差を認めてよいもの**もある（アレルギーの臨床的状態、傷病名の100桁）。
4. 本田さんに決めてほしいのは、**①基本スタンスと例外の線引き ②「3月は無理」と言われたときに求める時期と、それまでの暫定対応 ③照会の時点でスタンスを示すか、回答を待つか ④厚労省への上げ方**の4点。

## 1. 「対応できない」と回答されうる差と、スタンス（案）

| # | 差（Excelの行） | 機構の見込み回答 | スタンス（案） | 理由 |
|---|---|---|---|---|
| 1 | **名称の差**：検査項目・薬剤名・アレルギー物質（12・19・24・28行）。画面は医療機関が登録した名称、PDFはコードの表示名 | 10/5に「3月リリースでの修正は品質担保上困難」（富士通） | **修正を求める**（画面もPDFと同じく、コードの表示名で出す。ダミーコードは登録名称のまま） | 傷病名は案件213で同じ考え方の修正を進めている。区分によって画面の出し方が違うと、医療機関が混乱する |
| 2 | **案件221で画面が対象外**（12・28行）。PDF/XMLはJLAC11を優先するが、画面は対象外 | 「画面は3月では困難」（10/5） | **修正を求める**（#1と一緒に扱う） | 221の後はPDFだけ名称が変わり、差が広がる |
| 3 | **検査の「最新」**（29・31〜34行）。画面は臨床情報に紐づく検査、PDFは一番新しい検査 | 画面の構造上、最新は出せない、と回答される可能性 | **最低限、画面の項目名の修正を求める**（「最新」を外す等）。最新を出すことまで求めるかは相談 | 同じ「最新」という名前で違う値が出ると、医師が古い結果を最新と誤認するおそれがある。項目名の変更なら負担は小さいと見込む（推測） |
| 4 | **表示されるレコードの差**（共通の疑義②）。画面とPDFで出る病名・検査・アレルギーの条件が違う場合 | 回答待ち（差があるかは未確認） | 差がある場合は**修正を求める**。少なくとも、否定された傷病名・中止した検査が片方にだけ出る状態は直してもらう | 出てくるレコードが違えば、項目の出し方が同じでも同じ情報にならない |

## 2. 本田さんに決めてほしいこと

1. **基本スタンスは「修正を求める」でよいか**。例外（臨床的状態・100桁）の線引きはこれでよいか。
2. **「3月は無理」と言われたとき、いつまでの修正を求めるか**。あわせて、修正までの間の暫定対応（医療機関への周知、技術解説書に画面とPDFの違いを書く等）をセットで求めるか。
3. **照会の時点でスタンスを示すか**。示す場合は、返信本文に「対応が難しい場合も、修正の時期をご検討いただきたい」の一文を入れる（下の文案）。示さない場合は、回答を待ってから示す。
4. **厚労省への上げ方**。修正を求めるのは厚労省としての判断になるので、WBS確認会などで厚労省の了解をとってから機構に伝えるか、照会と並行して厚労省に共有するか。

## 3. 文案

### 3-1. 本田さんへの相談文（Teams）

```
本田さん

お疲れさまです。中澤です。
ToDo#1183の後続（臨床情報詳細画面とPDFの差異調査結果）について、機構への照会と並行して、1点ご相談させてください。

■ご相談
照会の結果、機構から「画面側は対応できない」と回答された場合の、厚労省としてのスタンスを事前に決めておきたいと考えています。
中澤の見立ては「基本は修正を求める」です。

■理由
・傷病名は、案件213（12月）で「画面をPDFと同じにする」修正をすでに進めており、他の区分（検査項目・薬剤名・アレルギー物質）だけ差を認める理由がないため
・10/5の検討会でも「全国展開が進む中で差が残る状態が続く」リスクが指摘されているため
・画面とPDFで同じ情報が違って見えると、医療機関の誤認・問い合わせにつながるため

■「対応できない」と言われうる差（4つ）
1. 名称の差（検査項目・薬剤名・アレルギー物質）：修正を求める
2. 案件221で画面が対象外：1と一緒に修正を求める
3. 検査の「最新」（画面は最新とは限らない）：最低限、画面の項目名の修正を求める
4. 画面とPDFで表示されるレコードの差（あれば）：修正を求める
※例外として、アレルギーの臨床的状態と傷病名の100桁は、差を認めてよいと考えています

■決めていただきたいこと
①基本スタンス（修正を求める）と例外の線引き
②「3月は無理」と言われたときに求める時期と、それまでの暫定対応（周知・技術解説書への明記）
③照会の時点でスタンスを示すか、回答を待つか
④厚労省への上げ方（WBSで了解をとるか、照会と並行して共有するか）

■資料
・相談事項の整理：20261014_内部相談事項_機構が対応不可の場合のスタンス_v1.md
・機構への照会（Rv依頼中）：20261014_PDFと詳細画面の差異_機構確認事項_v6.xlsx

よろしくお願いいたします。
```


## やったこと・やっていないこと

- **やったこと**：Excel v5の疑義のうち「対応できない」と回答されうるものを4つに整理し、スタンス（案）・例外・本田さんに決めてほしいこと・文案を作成した。
- **やっていないこと**：厚労省の意向の確認。修正にかかる費用・時期の見込み（機構・富士通の回答待ち）。案件化の要否の判断（本田さん・厚労省の判断）。
