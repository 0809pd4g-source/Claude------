# 「患者サマリーの運用の整理（1/4）通常パターン」機構の再コメントへの回答方針と厚労省への確認依頼

## 1. 結論

- **再コメント①（紙で渡す患者サマリーの扱い・位置付け）**：**厚労省（保険局医療課）の確認が必要**。ACNの見立ては「患者サマリーは療養計画書とは別の仕組みで、療養計画書の記載事項を入力すると、療養計画書の作成・交付とみなされるもの」。紙で渡すものを「療養計画書」と呼んでよいか、診療録に何と記録するかは、算定要件の解釈なのでACNでは決められない。
- **再コメント②（PDF出力機能は「推奨」ではなく必須では）**：**厚労省の判断が必要**。マイナポータルを使えない患者に「患者サマリーを印刷して渡す」運用を前提にするなら、機構の言うとおり印刷の手段は必須になる。一方で、そうした患者には**従来の紙の療養計画書を渡す**運用でよいなら、PDF出力は「推奨」のままでよい。どちらの運用にするかで書き方が決まる。

## 2. 再コメントごとの整理

### 再コメント①：紙で渡す患者サマリーの扱い・位置付け

**機構の再コメント（要旨）**
- マイナポータルを利用できない場合は、患者サマリーをPDF印刷して患者に渡し、診療録には「療養計画書を紙で患者に渡した旨」を記録する運用と理解している。この理解でよいか
- その場合、紙で渡す患者サマリーは「療養計画書」として扱う（呼ぶ）という認識でよいか
- 患者サマリーは、従来の紙の療養計画書を電子化したもの（名称だけ違うもの）か、それとも療養計画書とは別の文書で、療養計画書の内容を書けるものか

**通知の記載（令和8年度改定・生活習慣病管理料（Ⅱ）(5)）**
> (２)及び(４)について、患者の求めに応じて、電子カルテ情報共有サービスにおける患者サマリーに、療養計画書での記載事項を入力し、診療録にその記録及び患者の同意を得た旨を記録している場合は、療養計画書の作成及び交付をしているものとみなすものとする。（以下略）

**ACNの見立て（案）**
- 通知の書き方は「患者サマリーに療養計画書の記載事項を入力した場合に、療養計画書の作成・交付を**しているものとみなす**」なので、**患者サマリーは療養計画書そのもの（名称だけ違うもの）ではなく、別の仕組み**と読める（機構の2つ目の選択肢）
- そのため、紙で渡すものは「患者サマリーを印刷したもの」。診療録の記録も「療養計画書を紙で渡した旨」より「**患者サマリーを印刷して渡した旨**」の方が実態に合うのではないか（推論）
- ただし、紙で渡したものを療養計画書の交付として扱えるか、診療録に何と書けばよいかは、**算定要件の解釈**なので厚労省（保険局医療課）に確認する

**あわせて確認したいこと**
- マイナポータルを使えない患者に対して、①患者サマリーを印刷して渡す ②従来の紙の療養計画書を渡す、のどちらでもよいか（→ 再コメント②に直結）
- 患者サマリーを印刷して渡した場合も、通知(4)の「交付した当該療養計画書の写しは診療録に添付しておく」の扱い（写しの添付が要るか）

### 再コメント②：PDF出力機能は「推奨」ではなく必須では

**機構の再コメント（要旨）**
- 患者サマリー自体は任意の機能だが、患者サマリーを実装して本運用フローに沿う場合は、患者サマリーのPDF出力機能は必須になる認識。この点も踏まえて、「推奨」の表現などを検討してほしい

**これまでの厚労省回答（スライドの赤字・要旨）**
- 患者から紙の療養計画書を求められた場合は、患者サマリーを印刷して手渡すことができるようにする必要がある。上記の運用のためには、患者サマリーをPDF出力する機能の実装を電子カルテベンダに推奨する必要があるため、次回の技術解説書で記述する予定

**ACNの見立て（案）**
- 厚労省回答は「印刷して手渡すことが**できるようにする必要がある**」としているのに、その手段の実装は「推奨」になっている。**運用は必須、手段は推奨**という形で、機構の指摘には筋が通っている
- どちらに寄せるかは、マイナポータルを使えない患者に何を渡すかで決まる
- 前提の場面に注意：これまでの厚労省回答は「患者から紙の療養計画書を**求められた**場合」、機構の再コメントは「マイナポータルを**利用できない**場合」。同じ場面とは限らないため、確認依頼では両方の場面を並べて聞く

| 運用 | PDF出力機能の書き方 | 長所 | 短所 |
|---|---|---|---|
| A：マイナポータルを利用できない、または紙での交付を求められた患者に、患者サマリーを印刷して渡す（今の厚労省回答） | 「患者サマリーを用いて療養計画書の交付とみなす運用を行う場合は、**患者サマリーを印刷できる機能が必要**」（条件付きの必須） | 電子と紙で中身がそろう | 患者サマリーを実装するベンダに、PDF出力の開発を求めることになる |
| B：上記の患者には、従来の紙の療養計画書を渡す（または A・B どちらでも可） | 「推奨」のままでよい | ベンダの負担が増えない。今の紙運用の仕組みをそのまま使える | 同じ患者で、電子（患者サマリー）と紙（療養計画書）の中身がずれるおそれ。医療機関が2つの様式を持つ |

- 補足（確認したい点）：中央基盤（電カル共有サービス）側に、患者サマリーをPDFで取り出す仕組みがあるか。案件194・195（臨床情報一覧・患者サマリーのPDF帳票レイアウト。番号と件名はタスクリストの記載で、案件台帳では未確認）があるので、もし中央でPDFを出せるなら、ベンダ側のPDF出力機能は必須にしなくて済む可能性がある。一方、技術解説書 患者サマリー編 (8) には「患者サマリーは、マイナポータルの画面で表示することを前提に設計されているため、PDFファイルや画像ファイルを添付することはできません」とあり（添付の話で、出力の話ではない）、中央でのPDF出力の有無は手元の資料では確認できていない

## 3. 厚労省への確認依頼（文案）

```
（厚労省ご担当者様）

お世話になっております。アクセンチュアの中澤です。
「患者サマリーの運用の整理（1/4）通常パターン」について、DX機構から再度コメントをいただきました。算定要件の解釈に関わるため、以下2点についてご確認をお願いいたします。

■ご確認いただきたいこと
1. マイナポータルを利用できない、または紙での交付を求められた患者への対応
　（1）患者サマリーの位置付けは、「療養計画書とは別の仕組みで、療養計画書の記載事項を入力することで、療養計画書の作成・交付をしているとみなされるもの」という理解でよろしいでしょうか。
　　※通知（生活習慣病管理料（Ⅱ）(5)）の「患者サマリーに、療養計画書での記載事項を入力し…療養計画書の作成及び交付をしているものとみなすものとする」の書き方から、弊社としてはこのように理解しております。
　（2）上記の患者には、①患者サマリーを印刷して渡す ②従来の紙の療養計画書を渡す、のどちらで対応すればよいでしょうか（どちらでも可、も含めて）。
　（3）①の場合、紙で渡すものは「療養計画書」として扱ってよいでしょうか。また、診療録には何と記録すればよいでしょうか（例：「療養計画書を紙で渡した旨」か「患者サマリーを印刷して渡した旨」か）。
　（4）①の場合、通知(4)の「交付した当該療養計画書の写しは診療録に添付しておく」は必要でしょうか。

2. 電子カルテの「患者サマリーを印刷（PDF出力）する機能」の書き方
　先日、「患者から紙の療養計画書を求められた場合は、患者サマリーを印刷して手渡すことができるようにする必要がある。そのため、印刷（PDF出力）機能の実装を電子カルテベンダに推奨する旨を次回の技術解説書に記載する」との趣旨でご回答いただきました。
　これに対しDX機構から、「患者サマリーを実装し、このスライドの運用の流れに沿う場合は、印刷機能は必須になるため、『推奨』の表現を検討してほしい」とのコメントがありました。
　上記1（2）で①（印刷して渡す）とする場合は「患者サマリーを用いて療養計画書の交付とみなす運用を行う場合は、印刷できる機能が必要」と条件付きで必須とする書き方、②（従来の紙の療養計画書）も可とする場合は「推奨」のままとする書き方が考えられます。技術解説書の記載をどちらの方針とするか、ご教示いただけますでしょうか。

〇月〇日（〇）頃までにご教示いただけますと幸いです。
お忙しいところ恐れ入りますが、どうぞよろしくお願いいたします。
```

※「先日のご回答」の部分は、スライドの赤字（厚労省回答案）の文言と照合してから送る（手元はスクリーンショットのみ）。宛先・回答期限は本田さんと相談。

## やったこと・やっていないこと

- **やったこと**：機構の再コメント2点を、診療報酬改定通知（R8）の生活習慣病管理料（Ⅱ）(4)(5)と、技術解説書 患者サマリー編(8)に照らして整理し、回答方針・厚労省への確認依頼・機構への回答の骨子を作成した。
- **やっていないこと**：スライドの赤字（厚労省回答案）との文言の照合（原本なし）。スライドの他のコメント（左下の「電カル共有サービス登録前の算定について」等。ユーザー共有の画像では一部しか読めない）の確認。中央基盤で患者サマリーをPDF出力できるかの確認（案件194・195の内容。引継ぎのスレッド未確認）。厚労省の宛先・送付経路の確認。
