## 結論・要点

1. **いちばん大きい穴は「事業そのものの根拠資料」が手元にないこと**。調査研究の契約・仕様書（成果物と範囲）、電カル共有の根拠法令・運用マニュアル（10/1公開）、ロードマップが `_基盤/_input/` にない。ONSの同意の判断（緊急時の同意省略など）も、厚労省への説明も、ここが前提になる。→ C章の C1〜C4 を先に取り寄せる。
2. **残論点は「台帳の7件」だけではない**。各会議フォルダの「未確認事項」、daily のメモ、台帳どうしの食い違いに散らばっている。とくに**食い違い（D章 D2）は放置すると外に出る資料が誤る**ので、先に潰す。
3. **知識面は「自分の業務がサービスのどこに当たるか」の地図を持つと速くなる**。学習ノート（仕組み・関係）＋ 案件台帳 v3 ＋ 本ファイルの A章（制度・お金・時期）の3点で全体像はつかめる。
4. 進め方：**〜2026-10-23＝D2の食い違い潰しと期限超過**、**〜2026-10-31＝C1〜C4の取り寄せと B章の整理**、**11月以降＝学習ノートへの蓄積**（E章）。
