# プロジェクト状況

## 目的・概要
電カル共有サービスの案件管理。各案件の議論履歴・最新状況を一覧化した案件台帳HTMLを手元辞書として管理する。クライアントや会議資料を随時インプットし、常に最新化する。

## 位置づけ（電カル系の使い分け）

自分向けの案件・進捗の作業管理（手元辞書）。概要は『まとめ』、仕様参照は『ドキュメントポータル』を使う。

## 前提・スコープ
- 入力: `01_input/(原本)【電カル共有】案件台帳_令和8年度_20261009受領.xlsx`（最新。7/28受領の旧版も同フォルダに保存）、会議資料PPTX
- 出力: 単一ファイルHTML（外部依存なし、オフライン動作）
- 更新方法: `03_scripts/generate_html.py` を再実行 → `OUT_NAME` を `_vN+1` に変更してから実行
