# Copilotプロンプト集（Teams・SharePoint・メールから情報を取り出す）

> 作成日: 2026-10-09
> 用途：Claude Code は Teams・SharePoint・Outlook に直接つながっていない。Microsoft 365 Copilot で情報を**決まった形で**取り出し、Claude Code に貼り付けて、タスク一覧・日次メモ・議事録に振り分ける。
> 使い方：下のプロンプトの `{ }` を埋めて Copilot に貼る → 出てきた結果をそのまま Claude Code に貼り、「振り分けて」と頼む。

## 共通の約束（どのプロンプトにも入れてある）

- **原文の引用とリンクを付ける**：Copilotの要約は推測で埋めることがある。Claude側で元の投稿と照合できるようにする
- **見つからなければ「なし」と書く**（作らない）／**最後に件数を書く**（拾い漏れに気づけるように）
- **期間を日付で指定する**（「最近」「今週」にしない）

---

## A. メンションされた投稿・自分あての依頼（毎日 or 週明け）

引き継いだ業務（黒川さん・福島さんから移管）では、メンションされた投稿を全件確認するルールがある（定常業務マニュアル11章）。

```
{YYYY-MM-DD}から{YYYY-MM-DD}までに、Teamsのチャット・チャネルで私（中澤）がメンションされた投稿と、私あてに依頼・質問している投稿をすべて一覧にしてください。
次の列の表で出してください。要約で埋めず、分からない欄は「不明」と書いてください。
| 日時 | チャット／チャネル名 | 投稿者 | 内容の要旨（1行） | 私に求められていること | 期限（書かれていれば。なければ「なし」） | 返信済みか | 原文の冒頭（50字程度） | リンク |
最後に、件数と、返信していないものの件数を書いてください。該当がなければ「なし」と書いてください。
```

**Claudeがやること**：依頼・期限のあるものは `tasks_current.md` に追加（テーマタグ付き）、厚労省に確認・相談・報告するものは `daily/YYYYMMDD.md`「WBS向けメモ」に1行、残論点は `残論点台帳.md`。返信していないものを冒頭に⚠️で出す。

## B. スレッドの経緯（1本のスレッドをまとめて把握する）

```
Teamsの「{チャネル名 or チャット名}」で、「{件名・キーワード}」に関するスレッドの経緯を、古い順にまとめてください。
1. 時系列：| 日時 | 投稿者 | 内容（1〜2行） | 原文の冒頭（50字程度） |
2. 決まったこと（誰がいつ決めたか、その投稿の日時）
3. 決まっていないこと・確認待ち（誰の返事待ちか）
4. 次に誰が何をするか（書かれているものだけ。推測しない）
最後に、スレッドの投稿件数とリンクを書いてください。
```

**Claudeがやること**：決まったことを該当プロジェクトの `プロジェクト状況.md` に、確認待ちを `残論点台帳.md` に、WBSの確認事項一覧に載せるものは定常業務マニュアル8-2の型（内容・確認事項・今週の1文）で文案にする。

## C. 会議のトランスクリプト（逐語録の材料）

```
{YYYY-MM-DD}の会議「{会議名}」のトランスクリプトを、要約せずに次の形式で全文出してください。
[HH:MM] 発言者名: 発言内容
・発言者が分からない箇所は「話者不明」と書いてください（推測で名前を入れない）
・「えー」「あの」などのつなぎ言葉は省いてかまいません
・画面共有された資料名が分かれば、その時刻に「＊資料「〇〇」を画面共有」と1行入れてください
最後に、会議の開始・終了時刻と、参加者の一覧（名前・所属が分かれば所属も）を書いてください。
長くて一度に出せない場合は、「続き」と言ったら続きを出せるよう、途中の時刻で区切ってください。
```

**Claudeがやること**：`逐語録テンプレート.md` の形に整え、`/minutes` で議事録にする（`議事録・逐語録_共通ルール.md` §2・§8）。話者の確定は、議事要旨・参加者一覧と突き合わせる（自動の話者判定を過信しない）。

## D. メールの依頼事項（週明け・休み明け）

```
{YYYY-MM-DD}から{YYYY-MM-DD}までに受信したメールのうち、私（中澤）に対応・回答・確認を求めているものをすべて一覧にしてください。
| 受信日時 | 差出人（所属） | 件名 | 求められていること | 期限（なければ「なし」） | 返信済みか | 本文の該当箇所（50字程度） |
メールマガジン・自動通知・会議招集は除いてください。最後に件数を書いてください。該当がなければ「なし」と書いてください。
```

**Claudeがやること**：A と同じ（`tasks_current.md` への追加・締切カレンダーへの反映）。DX機構（芳原さん）からのterminology版数の問合せなど、マニュアルに手順がある定型の依頼は、手順の章を添えて出す。

## E. 今週の会議予定（週明けのタスク整理）

```
{YYYY-MM-DD}（月）から{YYYY-MM-DD}（金）までの私の予定表にある会議を、次の表で出してください。
| 日 | 曜日 | 開始–終了 | 会議名 | 主催者 | 先週から変わった点（時間変更・追加・キャンセル） |
同じ時間に重なっている会議があれば、備考に「重なり」と書いてください。最後に、日ごとの会議時間の合計を書いてください。
```

**Claudeがやること**：`会議一覧.md`「① 定常の会議」と照合し、違い（時間変更・追加・重なり）を⚠️で示して「② 週ごとの会議予定」に記録する。日ごとの会議時間は作業時間の見積もり（日次メモの会議時間・タスク時間の表）に使う。

## F. 厚労省に確認・相談・報告したもの（WBS資料の確認事項一覧の候補・木曜）

```
{YYYY-MM-DD}から{YYYY-MM-DD}までのTeamsのチャット・チャネルとメールで、厚生労働省の方に確認・相談・報告したもの、または厚生労働省の確認・判断待ちになっているものを一覧にしてください。
| 日時 | 場所（チャット名・チャネル名・メール件名） | 内容（1行） | 厚労省の誰に | 今の状況（回答済み／回答待ち／報告のみ） | 原文の冒頭（50字程度） |
ToDo台帳（Planner）で管理しているものは「台帳あり」と備考に書いてください。最後に件数を書いてください。
```

**Claudeがやること**：`daily/` の「WBS向けメモ」と突き合わせて拾い漏れを足し、定常業務マニュアル8-2「確認事項一覧欄」の型でスライド1行分の文案を作る。前回のスライドに同じ件があれば、その行の続き（「→MMDD）」）として書く。
