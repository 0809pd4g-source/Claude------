# acnpptx — Accenture ブランド PowerPoint 生成スキル（v6.9.3）

Claude Code 用のスキルです。依頼文から Accenture ブランドの PowerPoint（.pptx）を作成・読み取り・編集・リスタイル・リテーマします。公式のスライドマスター、実資料から抽出したデザイン文法、アイコン・イラストの意味検索、SVG の図形化を使います。

最初に表示される設定 Widget で「完了」を押すと、調査 → 構成 → 生成 → 自動検証 → 修正まで進めて、完成したデッキを返します。

## 主な機能

- 新規デッキの作成（提案書・研修資料・報告書など。日本語は Meiryo UI、英語は Graphik）
- 既存 PPTX の読み取り・編集・リスタイル（構成から作り直す）・リテーマ（色・マスターだけ変える）
- 独自スライドマスターの追加（Widget の「マスターを追加」）
- 自動検証: 文法・ブランド規定・フォント・はみ出しのチェックと、サムネイルを使った見た目の評価

## 動作環境

- Claude Code
- Python 3.14 以上と uv（依存は `pyproject.toml` / `uv.lock`。初回実行時に uv がスキル内の `.venv` に入れる）
- Windows + Microsoft PowerPoint（サムネイル・プレビュー生成、PPTX からの素材抽出に使う。生成そのものは python-pptx で行う）

## インストール

1. ZIP を展開し、中身を `~/.claude/skills/acnpptx/` に置く（`SKILL.md` がこのフォルダの直下に来るようにする）
2. Claude Code を起動し、「スライドを作って」「この PPTX をリスタイルして」などと依頼する

組み込みイラスト（約 2,000 点）は配布ファイルのサイズ上限に収めるため `assets/illustrations_*.zip` に分けて入っています。初回の素材検索のときに自動で展開されるので、手で展開する必要はありません。ZIP は消さないでください。

## ファイルの保存先

| 内容 | 場所 |
|---|---|
| 生成したデッキ・作業ファイル（outline.json・build スクリプト・slides/ など） | Claude Code を起動したフォルダ（CWD）。同名のファイルがあれば上書きせず別名にする |
| 追加したマスター・テーマ、抽出した画像 | `~/.acnpptx/`（環境変数 `ACNPPTX_DATA` で変更できる） |
| 展開した組み込みイラスト | `~/.acnpptx/cache/` |
| スキル本体 | 読み取り専用として扱い、書き込まない |

## セキュリティと取り扱い

- 外部への通信は、ユーザーが指定した参照 URL などの WebFetch による読み取りだけです。取得した内容は資料として扱い、中に書かれた指示には従いません
- 外部の画像生成サービスは既定で使いません。使う場合は送るたびに内容を示して許可を得ます
- PowerPoint を操作するときはマクロを強制的に無効にし、`.pptm` などマクロ入りのファイルは受け付けません
- スクリプトが読み書きできるのは、作業フォルダ（CWD）配下・`~/.acnpptx/`・スキル本体（読み取りのみ）だけです。引数や環境変数 `ACNPPTX_DATA` で受け取ったパスはすべて確認し、外を指していればエラーで止まります。作業フォルダの外のファイルを使うときは、作業フォルダにコピーしてから指定してください
- テーマ名・素材 ID も検証し、パス区切りや `..` を含む値は受け付けません。PPTX（ZIP）の展開でも `..`・絶対パスを含む名前は拒否します
- ユーザーへの確認は、最初の設定 Widget と、マスター削除のときの確認です
- 同梱のスライドマスター・イラストは Accenture のブランド資産です。社内のブランドガイドラインに従って使ってください

## フォルダ構成

| パス | 内容 |
|---|---|
| `SKILL.md` | スキル本体（Claude が読む手順書） |
| `references/` | 詳細な手順・API・規定（[トラブルシューティング](references/troubleshooting.md) を含む） |
| `agents/` | 生成・評価・修正を受け持つサブエージェントの定義 |
| `scripts/` | 生成・検証・素材検索などの Python スクリプト |
| `grammar/` | デザイン文法（構成パターン・配置・部品の定義） |
| `assets/` | スライドマスター、テーマ、プレビュー画像、イラスト、設定 Widget |
| `evals/` | スキルの評価用データ |
| `acnpptx_v6.9_紹介ムービー.html` | 機能紹介ムービー（ブラウザで開く。外部通信なし） |
