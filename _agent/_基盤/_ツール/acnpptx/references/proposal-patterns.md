# 人の提案書の型（v6.8）

人の提案書・報告書（4 デッキ、計 263 枚）から実測した型。寸法（インチ）・隙間・色の役割・文字の大きさ・文字の置き方だけを書く（文言・社名・資料名は載せない）。

## 共通の約束
- **文字は箱に直接書く**: 色の箱に文字がある 3,859 件のうち 95% は箱自身の文字（重ねたテキストボックスは 5%）。compose は描いた後に `merge_text_into_boxes` で、矩形の上に重ねたテキストボックスを箱の文字（余白＝位置の差）に書き直す。手で描くときも `_shape_text` か箱の `text_frame` に書く（TEXT-02）。
- **工程の見出しは「矢印：五方向」（homePlate）だけ**: 工程の見出しの行 126 本のうち 81% は五方向の矢印だけで描かれている（先頭だけ五方向で後ろをシェブロンにするのは 12%、シェブロンだけは 3%）。隙間の中央値は 0.03in（IQR 0〜0.10）。スキルは `compose.homeplate` を隙間 0.08in で並べ、矢じりは高さの 0.35 倍にそろえる。
- **中身の無いページを作らない**: 図のページでも各段・各箱に説明＋箇条書き（数字・固有名・手順・条件）を込める。読む資料で本文が意図別の p25 の 6 割未満なら grammar_check の DENSITY が ERROR。線の図で 250 字未満かつ下 1/3 が空いていれば craft_check が ERROR。

## 型と部品

| 型 | 使う場面 | 部品 |
|---|---|---|
| A 五方向の工程見出し | 工程・段の見出し | M-CHEVRON・M-PHASEGRID・M-RHMATRIX `col_style: "chevron"`・M-PIPELINE（すべて homePlate） |
| B 実績一覧 | 選ばれる理由の根拠（同業の案件の背景と、どの観点を支援したか） | **M-CASELIST** |
| C 五方向の大きな器 | 中長期の支援の全体像（研修・伴走・活躍の場など、段が積み上がる支援） | **M-PROGRAM** |
| D 2 段の進め方 | 全体の管理（1 行）＋チームの管理（工程ごと） | M-RHMATRIX `col_style: "chevron"`、全体の行は `why: true` |
| E KPI の木 | 投資対効果・削減率の内訳 | **M-TREE `style: "kpi"`** |
| F 成果物のイメージ | 主要アウトプットの見本 | **M-OUTPUTS** |
| G 作業の流れ×月のスケジュール | 全体スケジュール（担い手・マイルストーン・範囲） | **M-GANTT**（`group`・`phases`・`milestones`・`legend`・`scope`） |
| H メロン図（同心の帯のロードマップ） | 成熟度の段階×時期×道筋（ヒト・モノ・コト） | **M-MELON** |
| I 2 段の工程見出し＋列 | 工程のまとまり → 細かい工程ごとの実施項目、終わった工程・範囲の枠 | **M-RHMATRIX `groups`・セルの `status`/`done`・`scope`** |
| J 列×アクセント付きカード | 支援領域・注力領域（4 列×3 枚） | **M-COLCARDS** |
| K 下向き五方向の縦積み | 段階ごとの流れ＋右に条件 | M-STEPS（`G-SIDE` で右に M-ZONE） |

## B 実績一覧（M-CASELIST）
- 行は案件で、高さはすべて同じ（ピッチ約 0.95、隙間 0.05）。行ラベルの箱は 1.35in、その 0.1in 右に背景・狙いの文の箱。どちらも白地に 0.75pt の枠。
- 文は 12〜14pt。要点を太字（`**語**`）にする（人の資料は 35〜70% の字が太字）。
- ✓ の列は 1.2in ピッチで中央、見出しは 14pt で下線付き。✓ は 18pt 太字。一部だけの案件は灰の ✓＋「（計画中）」11pt。右端に着手時期の列。

```json
{"module": "M-CASELIST", "columns": ["プロジェクトの背景・狙い", "観点 1", "観点 2", "観点 3", "着手時期"],
 "rows": [{"label": "業界\nA 社", "text": "…**要点**…", "checks": [true, "partial", false], "date": "25 年 4 月"}]}
```

## C 五方向の大きな器（M-PROGRAM）
- 器は濃い紫の五方向の矢印（矢じり 0.45in）。上に題（24 太字・白）とリード（● 12pt・白）。
- 中に帯（淡い紫の五方向・16 太字）と、3〜4 枚の五方向のパネル（淡い紫・0.75pt の濃い紫の枠・隙間 0.08）。左に行ラベルの白い箱。
- パネルの左上に黒の番号丸（0.34in・パネルの上に少しはみ出す）。パネルの下に範囲を示す両矢印の線とラベル（白）。
- 器の下に土台の帯（白地に濃い紫の枠の五方向）と番号丸。右に強みの一覧（灰の箱に 0.75pt の枠、左の縁に黒の番号丸、14〜16 太字）。

## E KPI の木（M-TREE kpi）
- 根（濃い紫・18 太字・白）→ 中分類（紫・値を括弧で添える）→ 施策の箱（淡い紫 2.5in）＋値のセル（淡い紫 1.0in・太字の紫）。
- 枝は接続付きのカギ線（0.75pt）。右の具体例の箇条書き（11〜12pt）から値のセルへ短い ← の矢印。施策の行の間は 0.5pt の点線。
- 列見出し（「投資対効果」「方向性と改善率」「具体例」）は 14pt に下線。

## F 成果物のイメージ（M-OUTPUTS）
- 2×3 の見出し帯（濃い紫・16 太字・幅 3.8in・列の隙間 0.3）の 0.02in 下に、成果物の画像（約 3.9×2.1in）。
- 画像が無いときは、種類（`kind`: doc・table・chart・map・flow）に合わせた線画の見本を描く。

## G 作業の流れ×月のスケジュール（M-GANTT）
- 上から順に、年の帯 → 月の行 → 工程の帯（淡い紫の五方向）→ マイルストーン（▼＋11pt 太字）→ 作業の流れの行。
- 行見出しは灰の箱で、同じ流れの作業は縦に結合する。作業は五方向の矢印で、作業名はバーの中（11〜12pt）。同じ流れの作業は `lane` で同じ行に並べる。
- 担い手を塗りで分ける（アクセンチュア＝淡い紫、貴社＝白地に枠、共同＝明るい紫）。凡例は本文の右上（メッセージに重ねない）。
- 月の縦の点線はバーの下に描く。範囲の枠（コア紫 2.25pt）と札。

## H メロン図（M-MELON）
- 人の資料では帯を画像で描くが、スキルは図形で描く: 左下をそろえ、右上の角だけを楕円の弧で丸めた帯（custGeom）を外側から重ねる。内側ほど丸い（角の半径は幅の 55%→25%、高さの 90%→45%）。
- 段の色は内側から淡い灰 → ごく淡い紫（#F3E8FF）→ 淡い紫 → 明るい紫（ブランドの許可色だけ）（内側＝基礎。交互の色にしない）。左に段の名前の箱（帯と同じ色・14 太字）を、帯の左端に見える高さの中央に置く。
- 時期の枠は帯と同じ形の線（2.25pt。近い時期は濃い紫の実線、遠い時期はコア紫の破線）で、上に白地の札（14 太字）。
- ゴールは右上の濃い紫の箱（14 太字・白）。道筋は軸を自由に決める（ヒト・モノ・コト、業務・データ・システム、組織・業務・データ・システム など 2〜4 本。`tracks` の `label`）。道筋は左下からゴールへの曲線（0.75pt・灰）で、白い丸（0.13in）のマイルストーンと 11pt 太字の名前を置く。名前は丸・ほかの名前に重ならない側（右 → 左 → 上 → 下）に置き、置けなければ警告する（`t` で道筋の上の位置を指定できる）。

```json
{"module": "M-MELON", "levels": ["統制の基盤", "計測・可視化", "分析・改善", "自動化・最適化"],
 "horizons": [{"label": "2027 年度末", "level": 2}, {"label": "2029 年度以降", "level": 3, "dash": true}],
 "goal": ["開発者が 2 倍に増えても回る体制", "AI ネイティブな開発"],
 "tracks": [{"label": "ヒト", "milestones": ["推進チームの設立", {"label": "管理者の研修", "t": 0.35}]}]}
```

## I 2 段の工程見出し＋列（M-RHMATRIX）
- 上の段は工程のまとまり（濃い紫の五方向・0.36in・`span` で列をまたぐ）、下の段は細かい工程（淡い紫の五方向）。
- 列は 1.7〜2.2in で隙間 0.10〜0.12。セルは 11〜14pt の箇条書き（列が 5 つ以上なら 14pt まで）。
- 終わった工程のセルは灰（`done`）。状況の札（黒・11 太字・白）をセルの左上に載せる（`status`）。
- 範囲の枠（コア紫 2.25pt）で列・セルを囲み、右下に札を付ける（`scope`）。

## J 列×アクセント付きカード（M-COLCARDS）
- 見出し帯（濃い紫・3.1×1.0in・見出し 16 太字＋英語の副題 12）。その下にカードを 3 枚（淡い灰・高さは全列で同じ・隙間 0.09）。
- カードの左に 0.07in の紫の帯。紫の太字の題＋本文（11〜14pt）は、カード自身の文字として書く。下に列ごとのアイコン（0.7〜1.0in）。

## K 下向き五方向の縦積み
- 濃い紫の下向き五方向（1.4in 幅・隙間 0.09・14pt 白）の 0.15in 右に、灰の説明の面（16 太字の紫の題＋12pt の箇条書き）。
- 右に条件（チェックの箇条書き）と凡例・小さな棒グラフ。スキルでは M-STEPS（左）＋M-ZONE（右）で描く。
