## 運用ルール

- 公開資料のPDFもgitで管理する（URLが消えることがあるため。2026-10-09、医療DX工程表の旧URLが404だった）。ただし1ファイル10MBを超えるものは保存せず、URLだけ表に書く

- 機能IF一覧（Claude作成の二次資料）は2026-10-09に `_agent/02_仕様・技術/20260728_電カル情報共有ドキュメントポータル/02_output/20260909_電カル共有サービス_機能IF一覧_v1.md` へ移動した（Claude生成物はここに置かない）

- **追加時**: 上表に行を追記し、ファイルを `_input/` に置く
- **更新時**: 旧版ファイルを同フォルダに残しつつ新版を追加し、表の版・更新日を更新
- **削除不可**: 仕様書は版を重ねて保持（参照元の記録として残す）
- **重複注意**: 各プロジェクトの `01_input/` に同じ資料を置かない。ここを一次置き場とし、プロジェクト側には所在メモ（パスの記載）だけ置く
