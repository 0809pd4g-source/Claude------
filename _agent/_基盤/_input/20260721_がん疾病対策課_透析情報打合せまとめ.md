7/21時点　がん疾病対策課との透析情報についての打合せまとめです。

議題
電子カルテ情報共有サービスにおける透析情報の共有について

概要
電子カルテ情報共有サービスについて、運用開始時は傷病名や検査情報を中心に共有を行う予定であるが、運用開始後の共有情報の拡充についても引き続き検討を進めている。
医療・介護連携の観点から、医療機関と介護機関間での情報共有を検討している他、歯科情報、蘇生・ACP情報なども共有対象候補として議論中。また、規制改革の議論の中では画像情報や妊娠・出産関連情報の共有も検討されている。
こうした流れの中で、透析情報についても共有対象として検討を進めており、各担当課に協力を依頼した。

透析情報の共有に関する議論
透析医学会において透析情報の標準規格化が検討されており、現在も改訂作業が進められている。また、FHIRを用いた標準化の検討も行われているが、部門システムとの関係整理や内容の詳細な吟味は十分にできていない状況。
今後の情報共有方針について、がん疾病対策課においても検討をお願いしたい。共有を行う場合は時期をどう考えるかなども検討が必要。

電子カルテ情報共有サービスとの関係
透析情報の共有対象は、透析患者が入院した際に必要となる情報として、透析膜やドライウェイト、流速などの他、透析患者特有の薬剤処方、シャント部位の情報など。その他、透析情報の共有が医療費適正化に資するかどうかも検討が必要。

システム面の課題
透析システムと電子カルテシステムの構成は医療機関ごとに異なっている。

* 透析機器メーカーによってシステム仕様が異なる。
* 電子カルテと連携していない透析システムも存在する。
* 電子カルテではなくiPad等を利用して記録している医療機関もある。
* 電子カルテから閲覧できても、実際には別システムを起動して確認する構成のケースがある。
* 体重や血圧等のデータを部門システム側で管理している場合がある。
* 手書き運用が残っている施設もある。
* 透析や産婦人科では独自カルテが利用されている可能性がある。

このため、透析情報共有を実現するためには部門システムとの連携や標準化の整理が重要。

学会との連携
透析医学会と参事官室で過去やり取りはあったようだが記録が不明確。学会側の要望について整理しながら検討を進める必要あり。
透析システムの情報やカルテ情報の管理方法は施設によって差異があるものの、コアとなる情報項目については一定程度統一されている可能性がある。
透析医学会に対して、電子カルテ上での情報管理状況の確認や、学会資料を他課へ共有可能か確認が必要。

今後の検討事項
透析情報共有の目的について整理する必要あり。がん疾病対策課に対してサービスデザインの観点から検討への参画を依頼。

透析情報の電子化に関する意見
透析分野では、透析専用システムが長年利用されており、電子カルテとの乖離が生じている。透析医会では災害対応や臨床現場で必要となる情報の整理を進めており、E-MISとは別の仕組みで運用されている。
実際に必要となる透析情報は、10項目前後の情報で足りるのではないかとのご意見あり。

アクション項目

1. がん疾病対策課にも医療DXのteamsに入っていただく。
2. がん疾病対策課において透析情報の共有方針およびサービスデザインの観点からご検討いただく。
3. 共有対象となる透析情報の項目リストアップ。
4. 透析医学会資料の他課共有可否を確認。
5. 透析医学会との過去のやり取りや要望事項を整理する。

補足
木下参事官より、透析で必要となる項目数は限定的であることから、情報の二次利用についても比較的早期に実現可能ではないかとの意見あり。透析関連の年間コストを約2兆円とした場合、1％の効率化で約200億円の削減効果見込み。
