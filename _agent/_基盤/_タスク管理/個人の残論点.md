# 個人の残論点（＋プロジェクト課題の追跡メモ）

自分の管理用のローカルメモ（Claudeが管理）。**厚労省・機構と合意して更新している正式な台帳（SharePointの課題・ToDo管理台帳、WBS確認一覧、案件台帳）とは別物**。ここに書いても外には出ない。正式な台帳への追加・変更は、関係者と合意したうえでユーザーが行う。

旧名：残論点台帳.md（2026-10-09に改名・4節に分割）

**節の使い分け：**
| 節 | 何を書くか | 決める人 | 正本 |
|---|---|---|---|
| 1. 個人の残論点（R番号） | 自分の作業上の迷い・判断待ち | 自分・社内（本田さん等） | この節 |
| 2. プロジェクト課題の追跡（T番号） | すでに正式な台帳に載っている課題のうち、自分が関わるもの。番号と「どちらのボールか」だけ控え、内容は書き写さない | 厚労省・機構 | SharePointの正式な台帳 |
| 3. プロジェクト課題の候補（K番号） | 合意が要りそうだが、まだ正式な台帳に載っていないもの | 厚労省・機構（合意後に正式な台帳へ） | なし（候補） |
| 4. 外部への約束（P番号） | ONS等で「次回改訂で検討」と回答した事項 | ― | この節 |

**運用ルール：**
- 新しい論点はセッション中に随時追記する（起票日・タグ・関連タスクを必ず記入）。まず「1か3のどちらか」を判定する：厚労省・機構の判断や合意が要るなら3、自分・社内で決まるなら1
- 3（候補）が正式な台帳に載ったら、2へ移して正式な台帳の番号を書く。不要になったら「→ 不要（理由）」と書く
- 解決したらステータスを「✅ 解決済み（YYYY-MM-DD）」に更新する
- タグは `三者定例 / 開発進捗・課題検討会 / WBS / ONS / マスタ・周知 / 健診 / 血液型 / 横断` から選ぶ
