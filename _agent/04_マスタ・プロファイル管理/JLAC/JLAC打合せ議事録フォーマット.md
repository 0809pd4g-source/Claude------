## 1. ヘッダー部分

```
日時：YYYY年M月D日（曜）　HH:MM-HH:MM
参加者（敬称略）：
JLACセンター　氏名1、氏名2、氏名3
厚生労働省　氏名4、氏名5
アクセンチュア　氏名6、氏名7、氏名8（記）
資料：アジェンダ
```

- 参加者は組織ごとにまとめ、同一組織は氏名をカンマ区切り
- 議事録作成担当者の名前の後に **（記）** を付ける
- 「敬称略」表記あり

---

## 2. サマリーテーブル（冒頭）

全議題を表形式で一覧化する。列は「決定事項」「宿題事項」の2列。

```
　　　　　　　　　　　　　　　　　決定事項　　　　　宿題事項
1．【JLACセンター】議題名　　　　　―　　　　　　　―
2．000の位置づけ　　　　　　　　今年度はACが対応し、来年度以降は…　―
5．運用開始日・適用終了日の定義　―　　　　　　　　公開ページの記載を確認・修正する。【担当：アクセンチュア、期限：未定】
```

- 決定・宿題がない議題は「―」
- 宿題事項には **【担当：○○、期限：○○】** を末尾に付ける

議事（敬称略、当日資料の内容説明は割愛）

## 4. 議事本体のルール

### 4-1. セクションヘッダー

**正しい形式**: `【JLACセンター】eCS用JLACマスターの位置づけの定義`

- `【組織名】` + 議題タイトル
- Markdownの `###` や番号付き見出しは使わない

### 4-2. 発言者の表記位置

**正しい形式**: 発言内容の段落**末尾**に `（組織名　氏名）` を付ける

```
認識相違ない。UCUMの記述はFHIR上の要件となっているため、単位の項目として含めている状況である。（アクセンチュア　本田）
```

- 冒頭に置かない（誤り例: `（アクセンチュア　本田）認識相違ない。`）
- 組織名と氏名の間は全角スペース

### 4-3. 決定事項・宿題事項のインライン表記

議論の流れの中で結論が出た箇所に **【◎決定】** / **【★宿題】** をインラインで挿入する。

```
【◎決定】電子カルテ情報共有サービス用JLACマスターの作成対応については了解した。（JLACセンター　岡田）
```

宿題は担当・期限を末尾に明記：
```
【★宿題】公開ページの記載を確認し、必要に応じて修正する。【担当：アクセンチュア、期限：未定】
```

## 5. よくあるミス（Claudeが犯しやすい誤り）

| 誤り | 正しい書き方 |
|---|---|
| 発言者を段落の**冒頭**に置く | 発落の**末尾**に `（組織　氏名）` |
| `### 1. タイトル` 形式のヘッダー | `【JLACセンター】タイトル` 形式 |
| 宿題を `（担当：○○）` と括弧で書く | `【担当：○○、期限：○○】` と【】で書く |
| 参加者に役職・敬称を含める | 敬称略で氏名のみ |
| 決定・宿題を末尾の別セクションにまとめる | 議論の流れの中にインラインで挿入 |
