# プロジェクト状況：JLACマスター新旧対応表確認（2026-09-30）

## 目的

①電子カルテ情報共有サービスの新旧対応表で「販売終了（付け替え先検討中）」となっている試薬について、
②JLACオリジナルマスタ（日本臨床検査医学会）でも廃止扱い（AQ列=S or 削除）になっているかをダブルチェックする。

背景: 一度削除された試薬コードが②で復活するケースがあり、復活分を作成元に反映する依頼済み。その反映漏れを検出する。

## 前提の整理

- ①出所: 2026年度_電子カルテ情報共有サービス（SharePoint）> 20260915_公開用
- ②出所: 日本臨床検査医学会（JSLM）検査項目コード委員会ページ
- チェック条件: ①AH列=「販売終了（付け替え先検討中）」 → ②AQ列=「S」or ②に該当コードなし

## 手順

1. ①②をダウンロードして `01_input/` に配置
2. `python 03_scripts/check_jlac_master.py --inspect` で列名確認
3. スクリプト上部の設定（COL_CODE_1, COL_AH, COL_CODE_2, COL_AQ）を実際の列名に変更
4. `python 03_scripts/check_jlac_master.py` を実行
5. `02_output/確認結果_YYYYMMDD.xlsx` の「★要確認」シートを確認・報告
