## 2. 臨床情報リソースのidentifier（エーシーエス様・2回目）

### 経緯
- 1回目（8/28受付・9/16回答）：5情報リソースのidentifierもBundle.identifier同様の形式か → CLINS-IG 1.13.0 2.4のとおり「保険医療機関番号^発行年^施設内ID」。Bundle.identifierの施設内IDはハイフンも可（技術解説書は次回更新で修正検討）
- 今回（9/24受付）：この形式は5情報送信のときだけか（診療情報提供書など他のBundleには指定なしか）／Bundle.identifierとリソースのidentifierは同じルールでそれぞれ一意か
- 基金仮案（9/24）：IG 2.4は臨床情報Bundleのみの定義、2文書のリソース（Composition以外）は記述仕様で定義なし／2問目はご認識のとおり

### 回答案（最終）
```
【厚労省回答】（2026MMDD）
＞5情報送信するときのみBundleに組み込むリソースのidentifier要素にこのような値を設定するという認識で相違ないでしょうか?
＞例えば診療情報提供書など他の送信用のBundleに組み込むリソースのidentifier要素などについては特に値の指定は無いのでしょうか?
→
５情報を送信する場合に限らず、診療情報提供書・退院時サマリーに含まれるリソースのうち、５情報に該当するもの（AllergyIntolerance、Condition等）には、同じ形式の値を設定してください。（※1）
５情報に該当しないリソースのidentifier要素については、各HL7 FHIR記述仕様の別編「リソース記述に関する共通表」の各リソースの表をご確認ください。
例えば、表4 CarePlanリソースのidentifier要素は任意の要素であり、値の形式について特段の指定はございません。（※2）

＞またBundle.identifierと臨床情報のリソースのidentiferの値は現状の仕様では同じルールでそれぞれ一意になるように付ける認識で問題無いでしょうか?
→
ご認識のとおり、Bundle.identifierと臨床情報のリソースのidentifierは、同じ形式でそれぞれ一意となるように付番いただく認識で相違ございません。

-------------------【※1　参考：CLINS-IG1.13.0版「５情報送信仕様」抜粋】-------------------
2文書（診療情報提供書、退院時サマリー）に含まれる５情報に該当する情報の記述方法：
2文書の仕様書に記載されている５情報に該当する情報は、本実装ガイドに従い記述するものとする。
CLINSでは、2文書データは文書として取り扱われるとともに、これらの文書中に記述されている５情報に該当する情報は取り出され管理される。したがって、５情報をCLINSに送信するのと同じ仕様で記述しなければならない。
参照リンク：https://jpfhir.jp/fhir/clins/igv1/core6spec.html

## 3. 健診の取消・変更前に「登録情報の履歴照会」は必須か（2026-09-04受付・1回目）

### 経緯
- 健診結果報告書について、変更要求・取消要求の前に「登録情報の履歴照会」（機能14、TKK-IF-004／005）が必須か任意か
- ベンダの理解：（1）取消前の履歴照会は必須（技術解説書p.156）（2）変更前の履歴照会は任意（p.155に記載なし）

### 回答案（最終）
```
【厚労省回答】（2026MMDD）
＞（1）取消要求（CIS-IF-122／123）
＞→ 取消要求の前に履歴照会を実施し、データが存在する場合にのみ取消要求を行うことは必須、という理解でよいか。
→
ご認識のとおりです。
健診文書・臨床情報においては、本サービスへのデータの保存期間を超過して取消要求を行うと、本サービス上にデータが保存されていないためエラーとなります。
そのため、取消要求を行う際は、登録情報の履歴照会にて本サービスにデータが保存されていることを確認し、データが存在している場合にのみ取消要求を行ってください。（※1）
なお、この確認に利用するため、健診文書の登録情報の履歴照会（TKK-IF-004／005）は、電子カルテシステム等における実装が必須となっております。（※2）

＞（2）変更要求（CIS-IF-124／125）
＞→ 変更要求の前の履歴照会は必須ではない（任意）、という理解でよいか。
→
ご認識のとおりです。
変更要求の前に登録情報の履歴照会を行うことは、必須ではございません。

-------------------【※1　参考：技術解説書2.1.0版 P.156 抜粋】-------------------
