## 1. 概要・背景

JLACセンターが毎月1日に電カル共有向けのJLACマスタ（JLAC10/JLAC11コード対応表）を提出する。厚労省側（ACN担当）が内容をチェックし、疑義があればJLACセンターへ連携・修正を経て、15日頃に正式公開する。

**公開までの流れ（毎月）：**

| 時期 | 担当 | 作業 |
|---|---|---|
| N-2月末 | JLACセンター | 付番委員会でコード採択 |
| N-1月第1・2週 | JLACセンター | JSMLのHPで公開するマスタの整備 |
| N-1月第3・4週 | JLACセンター | 電カル共有向けマスタ整備 |
| N月1日 | JLACセンター | 電カル共有向けマスタ提出 |
| N月第1週 | **厚労省（ACN）** | **提出されたマスタのチェック** ← 本手順 |
| N月第2週 | JLACセンター | チェック結果の確認・反映 |
| N月15日頃 | 厚労省 | 電カル共有向けマスタの一般公開 |

> 今年度（令和8年度）は自動化推進中。令和9年度では早期提供を目指す。

## 3. 月次チェック手順

### Step 0：全行にチェックロジック適用（重複検出のため）

- チェックロジック（KA-01〜KA-M3、39件）を全行に対してかける
- **目的**：コード重複・構造エラーを見落とさないため（既存行も含めて一括チェック）
- 結果を「作業Excel」に出力し、問題箇所にコメントを記入する

### Step 1：既存行の確認（前月との差分チェック）

- 新規追加でない行（前月マスタに存在する行）について：
  - **Step 0で大量エラーが出ても一旦無視**（既存行のエラーは既知のものが多い）
  - **前月マスタとの差分がないかを確認**する
- 差分がある場合の判断：

| 差分の種類 | 判断 |
|---|---|
| 適用終了日 `99999999` → 特定の日付に変更 | **問題なし**（マスタ更新で切り替えが生じるため） |
| 適用終了日の日付が不自然（遠い未来・1日等） | **要確認**（おおよそ15日前後が想定、1日等は要確認） |
| 適用終了日以外の変更 | **要確認**（誤作業の可能性） |
| 行の削除 | **指摘する**（削除は想定外のため） |
| 適用終了日のバックデート | **要確認**（詳細判断基準：後日確認） |

> **見直し前コードについて：** 6月に一気に見直しを実施。古いコードは適用終了日を設定して放置（削除しない）。

### Step 2：新規追加行の確認

- 新規追加行（前月マスタに存在しない行）について：
  - **Step 0のチェックロジック結果を全件確認する**（問題が潜在する可能性があるため無視しない）
  - 新規行の見つけ方：基本的にExcelの下部に追加される（メールも要確認）

### Step 3：JLACセンター向けコメント記載（毎月1日の初回提出分のみ）

- 疑義事項をJLACセンター向けにコメントとして作業Excelに記載する
- **本田さんRv後（10/7まで）** にJLACセンターへ疑義を連携する

### 最終化（CSV化）時の注意

- 「**並び順**」列のフィルターで**昇順**にしてからCSV化する

## 7. ダミーコード（「その他」のコード）の作り方（2026-10-07 本田さんKT）

- 「その他」に分類されるコードは、**既存のコードから作る**
- JLAC11の測定法コード（**13〜15桁**）が **000** のものは「その他」に分類される（JLAC10では **999**）
- 作り方：
  1. 既存のJLAC11コードの13〜15桁を **000** に置き換える
  2. 置き換えた結果から**重複を除いた一覧**を作り、「その他」のコード一覧とする
- このコードを**ダミーコード**という（チェックロジックの KA-DUMMY・KA-33・KA-34 と関係する）
- 関連：日本衛生検査所協会打合せ（10/6）後の方針に「その他の測定法でマッピングすることであれば可能か」の検討がある
