    • 修飾語：候補が3つある（diseasenamecodes-modifiers＝MEDIS病名 修飾語管理番号／diseasename-exchangecodes-modifiers＝修飾語交換用コード／condition-disease-modifier-receipt＝レセプト電算用修飾語マスター）。「修飾語マスタ」は標準病名（MEDIS）側の管理番号を指すと判断して diseasenamecodes-modifiers を選んだ（2026-10時点では3つとも5.18.0で結果は同じ）

4-3. 行をまたぐチェック（グループ・重複）

「チェック」シートに、条件付きの集計列を作る。式は COUNTIFS またはピボットテーブルで同じことができる。

ID見ることやり方

9-3. なぜ3種類あるか（公開の考え方）

  • ポータルサイトには、マスタ2つ（新旧混合・新コードのみ）と新旧対応表を公開している（対応表はマスタではないが公開物）

  • ベンダー・医療機関には新コードでの対応を求めているので、「新しくマッピングするときはこちら」として新コードのみも公開する
  • 基盤で持っているものを非公開にするのは適切でないため、新旧混合も公開する
