## 3. 作成ツールでの作業（手順0〜11）

ツールの「本ツールの利用方法」シートの手順に従う。**数字（0、1、2…）が大項目、アルファベット（a、b、c…）が手で行う作業**。数字だけの項目（例：1「下3桁をZZZに変換」、3、4）は関数が自動で行うので、結果を見るだけでよい（KT）。シートや列は削除しない（非表示列で計算している）。

### 手順0：元データを最新にする

- **0-a 一般名処方マスタ**（a-1〜a-6）
  - 最新版のExcelをダウンロードし、**A〜E列（区分〜規格）を全行コピー**して、「一般名処方マスタ(令和YY年MM月DD日適用分まで)」シートの**最下行の次に貼り、「重複の削除」で整理**する（KT）。一般名コードを昇順にする
  - F列を「1」でフィルター → A〜E列を「一般名処方マスタ_重複削除」シートのA1に貼る
  - 同じシートのF列を「1」でフィルターしたままにする（重複コードのうち古い行が0）。シート名の「(令和YY年MM月DD日適用分まで)」も最新の適用日に直す
  - a-4：「一般名処方マスタ（例外コード表）」シートのB〜E列に、空欄がないように新規のコードを追加する。**廃止になったコードは削除しない**
  - a-5：同シートのX列を「1」でフィルター
  - a-6：同シートの**B〜V列**をコピーして**B2**に貼る。⚠️貼り先は、ツールの説明では「一般名処方マスタ_重複削除」だが、実物には別に「一般名処方マスタ（例外コード表）_重複削除」シートがあり、対応表（改修版）はこちらを参照している。どちらに貼るか要確認（10章#8）
  - 版が前回から変わっていなければ、この作業は要らない（2026-10-15時点の最新は令和8年6月12日適用で、ツールに入っている版と同じ）
- **0-b 薬価基準収載医薬品コード**
  - KTのやり方：最新のリスト（内用・注射・外用・歯科）のA〜D列を全行コピーし、シートの**最下行の次に貼って「重複の削除」**をする（先にある既存の行が残るので並びは変わらない）。新しく残った行の**E列に追加日**を入れる。**並べ替えない**。⚠️重複の判定に使う列（コードの列だけか、A〜D列全部か）は要確認
  - E列の既存の値は 20260415・20260615・20260815 など薬価の適用日と同じ日付になっている。⚠️適用日を入れる決まりかは要確認
  - シート名の「(令和YY年MM月DD日適用分まで)」も最新の適用日に直す
- **0-c YJ-list**：「YJ-list」シートのA〜F列を今月のYJコードリストに張り替える

## 4. CSVにする（手順12・13）

作成ツールから直接CSVにすると、重くて止まる（KT）。**別のExcelに値で切り出してから、CSV生成ツールで変換する。**

1. 新しいExcel（KTの例：`20260915_切り出し.xlsx`）を作り、3章の4つのシートをそれぞれ**値で貼り付け**る。シート名は短くする（9月の例：`剤形・規格・銘柄不明コードマスタ`・`YJ-mapping`・`薬剤アレルギー用コードマスタ`・`ippan-mapping`）
   - 出力シートは式で行が確保されていて空の行が多い（例：一般名処方は4,998行中データ1,647行）。**データのある最終行までを貼る**。CSVにした後、行数が前月と大きく違わないか確かめる（6-3のスクリプトでも出る）
   - ⚠️ツールの手順12は「1シート1ファイルに分ける」。1ファイルに4シートでよいか、CSV生成ツールに残っている前月の出力シート（`ippan-mapping` 等）を消してから動かすかは要確認（10章#12）
2. YJとの対応表のシートは、貼った後に**D〜F列を削除**する
3. 切り出しExcelを**CSV生成ツールと同じフォルダ**に置く。**そのフォルダに前月の切り出しファイルなどを置かない**（前月分が読み込まれたことがある。KT）
4. CSV生成ツールを開き、マクロを有効にする。「メインシート」に入れる
   - 標準マスタファイル名：切り出しExcelの名前（拡張子まで）
   - 標準マスタシート名：変換するシート名
   - 標準マスタデータ開始位置：A1（見出し行も出す）
   - 出力ファイル名：短い名前（例：`gcm`）。**ファイル名・シート名が長い、または日付・記号を含むとうまく動かない**（KT・Teamsのメモ）。正式名称にするのは最後
   - 出力ファイル拡張子：csv　出力ファイルエンコード：UTF-8
5. 出力ボタンを押す。うまくいくと、ツールに出力ファイル名と同じ名前のシートができ、同じフォルダにCSVができる。4シート分くり返す
6. できたCSVの名前を5章の正式名称に変える。YJコードリストも、受け取ったファイル名（例：`…_utf8.csv`）を正式名称に変える

## 6. 確認（前月版との比較）

**基本は、同じマスタの前月版と比べ、差分を1件ずつ見て「あってしかるべき変更か」を確かめる**（KT）。不自然な変更があれば、すぐ本田さんに報告する。

### 6-1. KTでの確認のしかた（アプリで並べる）

- 前月版と今月版を差分比較のアプリ（⚠️KTで使ったアプリ名は要確認）で左右に並べる。差分の行がオレンジ色になる。**コンテキストの行数を0にすると差分の行だけ表示**される
- **YJコードリスト**：メールに書かれた新規件数・変更件数と、差分の件数が合うか（9月：新規14件）。前月に「新規」「変更」だった行が今月空欄になるのは正常。コード（A列）など、変更区分以外が変わっていれば、正しい変更か確かめる
- **薬剤アレルギー用コードマスタ**：YJコードリストと同じ見方（右端の変更区分も同じように付く）
- **剤形・規格・銘柄不明コードマスタ**：手順9-eで自分で「新規」を付けた行が、前月に無かった行と一致しているか。前月の新規の印が残っていないか。不自然なコードの変更がないか。**コードが昇順か**
- 対応表2点：⚠️KTでは説明なし（6-3のスクリプトで点検する）

### 6-2. 確認の観点（まとめ）

| マスタ | 見ること |
|---|---|
| YJコードリスト | 新規・変更の件数がメールと合う／削除されたコードがない／変更区分の付かない変更がない |
| 薬剤アレルギー用 | YJコードリストの全行に「YCM」を付けたものと同じ |
| 剤形・規格・銘柄不明 | 昇順／コード・成分名の重複がない／前月のコードがすべて残る／新規に登録年月日と「新規」／前月の「新規」が消えている／既存コードの名称が変わっていない |
| YJとの対応表 | 5列／YJの並び・名称・会社名がYJコードリストと同じ／GCMコードがすべてマスタにあり、成分名もマスタと同じ／既存YJの紐づけ先が変わっていない |
| 一般名処方との対応表 | GCMコードがすべてマスタにあり、成分名も同じ／前月との差（出るのは主に、一般名処方マスタを更新した月か、GCMの成分名が増えた・変わった月。対応表は成分名でGCMマスタを引く式のため。9月公開版とツールの式からの見立て） |

### 6-3. 自動作成（Claude Codeの環境があるとき・内々の効率化用）

作成ツールの式をそのままPythonに写したもので、3〜5章のExcel作業とCSV化を省ける。**9月公開版の5点を、ツールに残っていた9月のインプットから1バイトも違わずに作れることを確認済み**（2026-10-15）。10月分も予測版と全行一致した。作成ツールが正式なやり方であることは変わらない（使うのは内々。黒川さん・本田さんへの切り替えの提案はしていない）。

```bash
python 00_共通/03_scripts/generate_yakuzai_master.py --state <前月の基準データ> --yj <今月のYJコードリスト> --prev-gcm <前月のGCMマスタCSV> --ym YYYYMM --ymd YYYYMMDD --date <新規の登録年月日> --out <出力フォルダ> [--yakka-new <厚労省の薬価基準xlsx…> --yakka-date <適用日>] [--ippan-new <一般名処方マスタxlsx>]
```

- 基準データ（薬価基準・一般名処方マスタ・例外コード表）は作成ツールのシートの中身をCSVにしたもの。最初の1回は `extract_state_from_tool.py` で作成ツールから書き出した（202610作成分/01_input/基準データ_202609/）。出力フォルダに「基準データ（翌月用）」ができるので、翌月はそれを `--state` に使う
- 出力：5点のCSV（正式名称・公開版と同じ書式）と「作成ログ.md」。ログの❌は直す、⚠️は判断する（後続品で先発品のコードが無い、前回11＝名称が合わなくなった既存コード、など）
- ⚠️まだ試していない経路：一般名処方マスタの更新（`--ippan-new`）、例外コード表の追加（手で `例外コード表.csv` に足す）、先発品の無い後続品。初めて出た月は作成ツールの結果とも突き合わせる
- 作成ツール（Excel）に戻るときは、ツールのシートに手順0の更新（薬価基準の追加など）を入れ忘れない

### 6-4. 点検スクリプト（Claude Codeの環境があるとき）

6-2をまとめて点検する。作成ツールの代わりではなく、作ったCSVを送る前の点検に使う。

```bash
python 00_共通/03_scripts/check_yakuzai_master.py --prev <前月公開版のフォルダ> --cur <今月のCSVのフォルダ> --yj-new <メールの新規件数> --yj-change <メールの変更件数> --out <報告.md>
```

- 結果は NG（直してから送る）／要確認（明細を見て判断）／情報／OK。ファイル名の正式名称、列数（非表示列の消し忘れ）、昇順も見る
- **答え合わせ用の予測版**：前月の公開版と今月のYJコードリストから、4種類の「こうなるはず」を作れる。新規YJが無く、一般名処方マスタの更新（0-a）も無い月は、ほぼ全行を予測できる（除外年月日を手で入れた行は外れる）。新規がある月は、同じ頭9桁の既存コードがあればその紐づけ先を使い、無いものは注記に出す

```bash
python 00_共通/03_scripts/make_expected.py --prev <前月公開版のフォルダ> --yj <今月のYJコードリスト> --ym YYYYMM --ymd YYYYMMDD --out <予測版のフォルダ>
python 00_共通/03_scripts/make_expected.py --compare <予測版のフォルダ> <作成したCSVのフォルダ>
```

- 予測版は送付物には使わない（作成ツールでの作成が正）。違う行が出たら、どちらが正しいか作成ツールのシートで確かめる

## 7. 送付までの流れ

1. YJコードリストを受け取る（7-1のメール）。ZIPを解凍し、メールの「先月との差分」の件数を控える（6-3の `--yj-new`・`--yj-change` に入れる）
2. 3〜5章で作り、6章で確認する
3. Teamsのスレッドで**まず黒川さんにメンション**して連絡し、格納先（スレッドにリンクあり）に**その月のフォルダを作って格納**する。2026-10は、黒川さんが並行して作成し、本田さんの確認の前に照合する（KT）
4. 本田さんにRvを依頼する（受け取った翌日）
5. 送付する（Rvの当日中）。⚠️送付先・送り方は要確認

### 7-1. YJコードリストのご案内メール（2026-10の例）

- 件名「個別医薬品コード(YJコード)リストのご案内」。本文に「今月更新の標記情報」、DLリンク・DLパス、**先月との差分**、形式（UTF8形式をZIP化）がある
- 先月との差分の書き方（2026-10）：「最新：2026年10月月初」「変更：4品目」。新規の行は無く、CSVでも新規0件・変更4件だった。⚠️「最新：…月初」が何を表すか（情報の時点か）、新規があるときの書き方は要確認（9月は新規14品目だった。KT）
- 気づいた点があれば送り主に連絡してよい、とメールにある（DL不具合・ファイルの内容）

### 7-2. Claude Codeへの依頼のしかた（自動作成を使う月）

1. YJコードリストのメールが来たら、ZIPをダウンロードして解凍する（パスワードはメールにある）
2. Claude Codeに「薬剤関連マスタ YYYYMM をお願い」と伝え、解凍したCSVの場所と、メールの「先月との差分」（新規・変更の件数）を渡す。メールの画面の貼り付けでもよい
3. Claudeがやること：その月のフォルダを作る → 前月の5点と基準データを引き継ぐ → 厚労省の薬価基準・一般名処方マスタの版を確かめ、新しければ取り込む → 自動作成 → 予測版・点検スクリプトで確認 → 結果と判断が要る点を報告する
4. 担当者がやること：報告を見て、判断が要る点があれば本田さんに相談 → 格納・本田さんRv → 送付
