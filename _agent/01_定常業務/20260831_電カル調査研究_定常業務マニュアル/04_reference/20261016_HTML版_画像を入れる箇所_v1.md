# HTML版マニュアル：画像を入れる箇所の洗い出し

> 作成日: 2026-10-16
> プロジェクト: 20260831_電カル調査研究_定常業務マニュアル
> 用途: HTML版（`03_scripts/build_manual_html.py` で生成）に入れる画像・図の候補と、素材の入手方法を決める
> 前提: 正本はMD。画像はMDに `![説明](images/ファイル名.png)` と書き、生成時にbase64でHTMLに埋め込む（生成器は対応済み）。画像の置き場は `02_output/images/`（案）

## 1. 選び方

後輩が「どこを・何を見ればよいか」を文章だけでは掴みにくい箇所を優先した。優先度は次のとおり。

- **A**：文章で列・シート・色を指定していて、画像がないと迷う箇所
- **B**：画像があると速く理解できる箇所
- **C**：あると親切な箇所

## 4. 進め方の案

1. 2章のA（#1〜#5）を作り、MDに画像の行を入れてHTMLを作り直す（1回目）
2. 図（#9〜#12）を作る
3. 3章のスクリーンショットは、ユーザーが撮れたものから順に `02_output/images/` に置いてもらい、MDに入れる

## 5. 決めておくこと

- 画像の大きさの上限：1枚300KB程度、HTML全体で10MB以内を目安とする（メール添付・Teams共有を想定）
- 個人名・メールアドレス・パスワード・URLの写り込みは、画像にする時点で塗る
- 画像は、元のExcel・スライドが変わると古くなる。版が上がったら撮り直すかを、手順書の改訂のときに確かめる

## 6. やったこと・やっていないこと

- やったこと：定常業務マニュアルv51・JLAC手順書v11・手作業編・薬剤手順書・J-FAGY手順書から、列・シート・色・画面を文章で指定している箇所を拾い、手元にある素材（`_agent/` 配下のxlsx・pptx）と対応させた
- やっていないこと：画像の作成。素材ファイルの中身の確認（シート名・スライド番号は、作るときに確かめる）。三者定例資料（`07_ONS問合せ対応/ONS月次報告/202610/01_input/三者定例資料_20261009.pptx`）にワッペンの例があるかの確認
