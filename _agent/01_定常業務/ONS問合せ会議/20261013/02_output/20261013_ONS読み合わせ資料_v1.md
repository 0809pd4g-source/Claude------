## 1. #525 退院時サマリーの追加送付（方式②）で受け手の混乱をどう避けるか（エーシーエス様・2回目）

### 経緯
- 1回目（8/31）：技術解説書P.41の追加送付の方式①②③について質問。②は「コピーした診療情報提供書を追加で登録する」ことか、受け手が混乱しないか
- 厚労省回答（9/25）：「医療機関間での運用上の連絡方法等について、導入先医療機関とご調整の上、追加送付方法の実装方針をご検討ください」
- 2回目（9/25）：②は**システム上で**どうすれば混乱を避けられるか。電話で事前に連絡するなど、システムの外での対応が必要になると思うがどうすればよいか。「調整」の想定案を教えてほしい
- 台帳L列（黒川さん）：「★0929回答方針確認不要」「読み合わせのとき、『退院時サマリーを送るときは必ず送付先と調整してから』を医療事務の方向けに周知する媒体を相談する（指針には記載がないと思われる）」

### 聞かれていること（1行）
②の方式で受け手の混乱を避けるには、システムの外の連絡（電話等）が必要か。調整の想定案は何か。

### 回答案（ACN案）
```
【厚労省回答】（2026MMDD）
＞この②はシステム上でどのようにすれば混乱を回避できますか。「導入先医療機関とご調整の上」とありますが、追加送付前に連携先の医療機関のシステム担当者へ電話などで事前連絡をいれるなどのシステム外での追加対応が必要になると思うのですが、どうすればよいでしょうか。
＞「導入先医療機関とご調整の上」とありますが、どのように調整したらよいか想定されている案を教えてください。
→
ご認識のとおり、追加送付を行う際は、紹介先医療機関へ事前に電話等で連絡するなど、医療機関間での運用上の連絡を想定しております。
技術解説書では、紹介元医療機関の運用上追加送付が発生するかや、追加送付時の紹介先医療機関とのコミュニケーション方法を確認の上、追加送付の方式を選択いただくこととしております。（※1）
導入先医療機関とのご調整にあたっては、例えば、どのような場合に追加送付が発生するか（診療情報提供書の送付時点で退院時サマリーが作成途中の場合等）と、追加送付時の紹介先医療機関への連絡方法を、あらかじめご確認いただくことが考えられます。

なお、同じ内容の診療情報提供書が紹介先医療機関に重ねて届くことを避けたい場合は、③の方式（頭紙（送付票）を作成し、退院時サマリーを添付して新しい文書として登録する方式）を選択いただくことも可能です。（※2）

-------------------【※1　参考：技術解説書2.1.0版 P.41 抜粋】-------------------
追加送付には以下の方式があります。紹介元医療機関の運用上追加送付が発生するかや、追加送付時の紹介先医療機関とのコミュニケーション方法を確認の上、方式を選択してください。
--------------------------------------------------------------------------------

-------------------【※2　参考：技術解説書2.1.0版 P.50 抜粋】-------------------
(9) 退院時サマリーを追加送付する場合の頭紙（送付票）の記述方法（退院時サマリーのみ）
実装は任意ですが、診療情報提供書と切り離して、退院時サマリーを単独で追加送付したい場合は、診療情報提供書の FHIR 記述仕様に準拠した代替となる頭紙（送付票）を作成することで送付が可能です。
--------------------------------------------------------------------------------
```

## 2. #537 臨床情報の登録タイミングを制御する機能は必須か（SBS情報システム様・1回目）

### 経緯
- モデル事業のベンダ。電子カルテ本体ではなく外部の「送受信アプリ」から、医師等が確認して手動で登録している
- モデル事業では、登録タイミングを制御する機能（自動登録、退院日までの登録を促す機能等）は作らず、運用（外来は同日中、入院は退院日当日中に登録）で対応したい
- 質問：(1) p.74の登録タイミング（外来の目安・リアルタイム処理）は推奨で、制御する機能は必須ではないか (2) 退院日当日中の登録は、モデル事業の期間は機能でなく運用（手動登録）で担保してよいか (3) モデル事業中と本格運用で取扱いが違えばそれぞれ教えてほしい (4) 機能が必要なら最低限の範囲
- 台帳L列（黒川さん）：「★モデルチームに方針確認」→「(3)だけ『取扱いは変わらない』を確認してもよいが、中西さんへの確認でも足りる（モデル期間中と全国運用開始後の取扱いを同じにしないと検証にならない）」

### 聞かれていること（1行）
登録タイミングを機能で制御しなくてよいか（運用・手動登録でよいか）。モデル事業中と本格運用で違うか。

### 回答案（ACN案）
```
【厚労省回答】（2026MMDD）
＞(1) p.74に示された登録タイミング（外来の目安およびリアルタイム処理）は推奨事項であり、技術解説書v2.1.0への対応の完了にあたって、登録タイミングを制御する機能を備えることは必須ではない、という理解でよろしいでしょうか。
→
ご認識のとおりです。
臨床情報の具体的な登録タイミングは各医療機関の判断に委ねており、外来診療における登録タイミングの目安およびリアルタイム処理は推奨としてお示ししているものです。
登録タイミングを制御する機能（カルテ画面を閉じたタイミングでの自動登録等）を備えることは必須としておりません。（※）

＞(2) 入院中に発生した臨床情報を退院日当日中までに登録することについて、このモデル事業期間においては、システムの機能で担保する必要はなく、医療機関の運用（手動登録）により担保することで差し支えないでしょうか。
→
差し支えございません。医師等の判断により手動登録とすることも可能です。（※）
ただし、入院中に発生した臨床情報は「退院日当日中（夜間登録も可）」までに登録いただく必要がございますので、登録漏れが生じないよう運用にてご対応ください。
また、入院中に実施した検査・感染症検査のうち、退院日までに結果が確定しないものについては、検査結果を電子カルテに登録した、または検査システム等から電子カルテに連携されたタイミングで登録いただくようお願いいたします。（※）

＞(3) (1)(2)の取扱いが、モデル事業の期間中と、モデル事業後の本格運用とで異なる場合は、それぞれの取扱いをご教示いただけますと幸いです。
→
(1)(2)の取扱いは、モデル事業の期間中と全国での運用開始後とで同じです。【要確認：中西さん】

＞(4) (1)(2)のいずれかについて機能での対応が必要な場合、最低限求められる機能の範囲（例：登録漏れの通知機能で足りるか、自動登録が必要か）をご教示いただけますでしょうか。
→
(1)(2)のとおり、登録タイミングについて機能での対応は必須としておりません。

-------------------【※　参考：技術解説書2.1.0版 P.74 抜粋】-------------------
臨床情報の具体的な登録タイミングは、医療機関の規模や診療特性を踏まえて各医療機関の判断に委ねるものとします。（中略）
なお、上記のタイミングでの即時登録に限らず、夜間にまとめて登録いただくことも可能ですが、受診日当日における他医療機関や薬局で臨床情報を閲覧するケースを踏まえ、臨床情報の登録はリアルタイム処理を推奨します。（中略）
一方、入院中に発生した臨床情報については、入院中に他医療機関等で当該情報を参照する必要が生じるケースが少ないことを踏まえ、「退院日当日中（夜間登録も可）」までに登録してください。ただし、入院中に実施した検査や感染症検査のうち、退院日までに結果が確定しないものについては、検査結果を電子カルテに登録した、または検査システム等から電子カルテに連携されたタイミングで登録するものとします。
また、本サービスの利用にあたっては、医師等の業務負荷の軽減に十分配慮する必要があります。たとえば、患者のカルテ画面を閉じたタイミングで自動的に登録する仕組みや、検査結果がシステムに取り込まれた時点で自動登録を行う仕組みなどが考えられます。ただし、運用上のトラブルを回避するため、医師等の判断により手動登録を選択できるようにすることも可能です。
--------------------------------------------------------------------------------
```
