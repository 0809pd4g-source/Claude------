## 3. CC向け回答文案

会議メモの「指針、FAQ」を、回答で案内する資料と読んだ（推論）。指針・FAQに該当の記載があるかで、2案を用意した。

### 案A：指針・FAQに記載がある場合（参照先を案内する）

```
【厚労省回答】（2026MMDD）
コンタクトセンターご担当者様

お問い合わせの件、医療機関様へは以下のとおりご案内いただけますでしょうか。

＜ご案内内容＞
電子カルテ情報共有サービスへの情報登録を希望されない患者への対応については、「〔指針の名称〕」の〔章・項目〕、および「〔FAQの名称〕」の〔FAQ番号〕に考え方を記載しておりますので、ご参照ください。
なお、情報共有を希望しない旨の申し出があった場合の意思表示の記録（書面・本人の署名）の要否については、〔指針・FAQの記載内容。記載がない場合は「現在検討を進めており、詳細が決まり次第、改めてご案内いたします」〕。
```

### 案B：指針・FAQに記載がない場合（9月の回答と同じ趣旨）

```
【厚労省回答】（2026MMDD）
コンタクトセンターご担当者様

お問い合わせの件、医療機関様へは以下のとおりご案内いただけますでしょうか。

＜ご案内内容＞
現在、電子カルテ情報共有サービスにおいてはモデル事業を実施しており、本サービスへの情報登録を希望されない患者への対応（院内掲示による周知と、情報共有を希望しない旨の申し出があった場合の対応、およびその意思表示の記録の要否を含む）については、現在検討を進めております。
詳細が決まり次第、改めてご案内いたします。
```

## 4. 確認が必要な点

- 会議で出た「指針」「FAQ」は、どの資料か（名称・版・掲載先）。該当の記載があるか → 案A・Bのどちらにするかが決まる
- 「CC向けの回答」の意味：CCが医療機関へそのまま伝えられる形（上の文案）でよいか、CCの応対用の想定問答（FAQ形式）まで作るのか
- オプトアウトの話のスレッド（Teams）の内容。案件050（令和9年度以降）との関係で、モデル事業外の医療機関に「今はどう運用すればよいか」を示す方針が出ていないか
