# 別紙4-2 業務コード一覧（薬剤情報等・特定健診情報・臨床情報）

- 版数: 5.02
- 更新日: 2024/10/18
- システム名: オンライン資格確認等システム
- 機能名: 薬剤情報等・特定健診情報・臨床情報管理機能

> 薬剤情報等・特定健診情報・臨床情報の取得は、患者からの閲覧同意を得たうえで、医療機関・薬局が必要と判断した場合のみ使用してください。
