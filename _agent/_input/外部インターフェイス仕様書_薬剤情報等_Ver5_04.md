### 1.3 本書の対象

既存システムと薬剤情報等・特定健診情報・臨床情報管理機能間は「連携アプリケーション」を使用した処理方式とする。
概念図は「オンライン資格確認システム「外部インターフェイス仕様書」」の「1.3 本書の対象」を参照する。
なお、「オンライン資格確認システム」は「オンライン資格確認等システム（薬剤情報等・特定健診情報・臨床情報管理機能）」と読み替える。


薬剤情報等・特定健診情報・臨床情報の閲覧同意については、資格確認結果に連携されるため、出力内容については「別紙 3-1 XML レイアウト（オンライン
資格確認）」を確認すること。
なお、閲覧同意の有効期間は下記の通りとする。
外来の場合       ：同意取得後 24 時間
訪問診療等の場合       ：無期限（ただし、一定期間レセプト請求がない場合は無効となる。）
オンライン診療等の場合    ：受診日
救急時の場合         ：閲覧実施の度に同意を取得（期限で管理しない）

2. 処理方式

### 2.1 連携アプリケーション

「連携アプリケーション」は、オンライン資格確認端末の Web 画面を使用せず、既存システムから薬剤情報等・特定健診情報・臨床情報管理機能を使用する処理
方式である。既存システムからネットワークで接続したオンライン資格確認端末に対して要求ファイルを送ることで、薬剤情報等・特定健診情報・臨床情報管理機能を呼
び出し、結果ファイルを取得する。
「連携アプリケーション」の処理イメージ概念図は「オンライン資格確認システム「外部インターフェイス仕様書」」の「2.1 連携アプリケーション」を参照する。

「連携アプリケーション（単件）」により、結果ファイルを取得する手順について、以下に示す。
① 既存システムで要求ファイルを作成する。


② 要求ファイルを「共用フォルダ（要求用）」に転送する。


③ タスクスケジューラで連携アプリケーションの定期起動を行い、要求ファイルが転送されたことを検知し、連携アプリケーションの処理が開始される。


④ 薬剤情報等・特定健診情報・臨床情報管理機能の WebAPI が呼び出され、要求ファイルがアップロードされる。
（アップロード後、「共用フォルダ（要求用）」内の要求ファイルは削除される。）


⑤ アップロード完了後、薬剤情報等・特定健診情報・臨床情報管理機能側で処理が行われ、結果ファイルが「共用フォルダ（結果用）」に出力され
る。
（要求対象のファイル形式が PDF の場合、結果ファイル（PDF）が出力される。なお、対象者の資格情報が存在しない等の場合、
処理結果メッセージ等が格納された結果ファイル（XML）が出力される。
要求対象のファイル形式が XML の場合、結果ファイル（XML）が出力される。）


⑥ 「共用フォルダ（結果用）」から結果ファイルを既存システムに取得する。
（取得後、既存システムが「共用フォルダ（結果用）」内の結果ファイルを削除する。）


⑦ PDF 帳票または、XML データを確認し、使用する。


※ 薬剤情報等、特定健診情報・臨床情報は機微な情報であるため、結果ファイルを取得後は「共用フォルダ（結果用）」から必ず削除すること。
また、ファイルの消し忘れを防止するための、消し忘れファイルの削除機能の使用を推奨する。
（消し忘れファイルの削除機能については「6.1 消し忘れファイルの削除機能（任意）」を参照）
