### ここからプロンプト

あなたが作成した `ライフプラン_住宅購入シミュレーター_不安見える化・住宅種別対応版.html` を査読しました。
設計の良い点（安心診断の判定基準をユーザーが設定できる点、現在価値での表示、
妻年収ストレステストと損益分岐点、プラン管理の充実、東京都の第1子無償化への対応）は
そのまま維持してください。そのうえで、以下の点を修正してください。

#### P0-1　社会保険料の計算に上限が入っていない（金額の誤りが大きい）

`approximateTax()` の中で社会保険料を次のように計算しています。

```js
const social = salary * num(b.socialRate);
```

年収に単一の率を掛けているため、**厚生年金保険料の標準報酬月額の上限（月65万円）が
効いていません。** 年収が高いほど過大に計算されます。

具体的には、年収1,500万円の場合：
- 単一率15%なら225万円
- 正しくは、厚生年金は標準報酬月額65万円で打ち止めになるため約157万円
- **差は年68万円**で、これが40年分と運用利回りで増幅されます

次のように、保険料ごとに正しい仕組みで計算してください。

- **厚生年金保険料**：標準報酬月額（上限65万円）× 18.3% ÷ 2（労使折半）× 12
  ＋ 標準賞与額（1回150万円が上限）× 18.3% ÷ 2
- **健康保険料**：標準報酬月額（上限139万円）× 料率 ÷ 2 × 12 ＋ 賞与分
  （料率は協会けんぽなら都道府県ごと、組合健保なら組合ごと）
- **介護保険料**：40歳以上のみ加算
- **雇用保険料**：年収 × 本人負担率（上限なし）

上限を入れると、この世帯（世帯主800万→1,212万、配偶者884万）では
**社会保険料が年15〜20万円減り、生涯の資産で500〜600万円の差**になります。

なお、参照元のFP診断書自体もこの上限を適用していないため、
PDF再現モードでは現状の計算を残し、**現行制度モードでは上限を適用する**という
切り分けにしてください。

#### P0-2　住民税の課税年がずれている

住民税は前年の所得に対して翌年6月から納付します。現在は同年の所得から
同年に計上しているため、**収入が大きく変わる年（育休の開始・復職、退職、
リタイア）の前後で1年ずれます。**

とくに退職した翌年は、収入がないのに前年の高い所得に対する住民税を
払うことになるため、キャッシュフローの谷が実際より浅く出ています。

前年所得から計算して翌年に計上するよう改めてください。初年度は
前年所得を入力できるようにするか、FP資料の値を使ってください。

#### P0-3　入力欄の配色が読みにくい

```css
.field input { background: var(--yellow); color: #003eff; }
```

黄色の背景に青文字という組み合わせで、コントラストが不足しています。
Excelの入力セルの慣習だと思いますが、画面では読みにくく、
とくに高齢の方や色覚特性のある方には負担です。

背景は白または淡いグレー、文字は濃いグレーか黒にして、
「入力できる欄」であることは枠線かラベルで示してください。
WCAG AAのコントラスト比4.5:1を満たすようにしてください。

#### P0-4　自治体プリセットが3つしかなく、地域比較ができない

`LOCATION_PRESETS_V4` は `fp` / `tokyo` / `custom` の3つだけです。
ツールの目的が「東京とその他首都圏の子育て支援差を考慮して、
どこに家を買うべきか」であるなら、**比較対象となる他自治体の値が必要**です。

少なくとも次を選べるようにしてください（いずれも0〜2歳の最高所得階層の目安）。

- 横浜市・川崎市（月7万円台）
- さいたま市（月7万円台後半）
- 千葉市（月6万円台）
- 認可外保育園を使う場合（無償化の対象外。月5〜10万円）

**「認可外を使う場合」は特に重要です。** 東京都の第1子無償化は認可保育所等に
入れた場合の話で、認可に入れなければ無償化の対象外になります。
待機児童の状況によっては現実的なシナリオなので、比較できるようにしてください。

あわせて、各プリセットに次を持たせて画面とPDFに表示してください。

- 基準日（`asOfDate`）
- 出典の名称とURL
- その金額を出典で直接確認したか、推定値か（`verified`）

#### P1-1　シミュレーション期間が固定されている

```html
<input type="number" value="72" readonly>
```

72年で固定され、`readonly` になっています。世帯主の最終年齢を
変更できるようにしてください（相続の想定年齢を変えたい場合などに必要です）。

#### P1-2　年金額が収入と連動していない

`defaultOwnerPension()` / `defaultSpouseSalary()` を見ると、年金額は
固定値または簡易な設定値です。**妻の年収を下げるストレステストをしても、
将来の年金額が変わりません。**

厚生年金は報酬比例なので、収入が下がれば年金も下がります。
実測すると、配偶者の年収が884万円から500万円に下がると
**年金は年257万円から206万円へ、年51万円下がります**（30年で1,530万円）。

これを反映しないと、収入が低いシナリオが実際より楽に見えます。
次の式で収入設定から自動計算し、手入力との切替を残してください。

- 老齢基礎年金＝満額（2025年度 831,700円）× 保険料納付月数 ÷ 480
- 老齢厚生年金＝平均標準報酬額 × 5.481 ÷ 1000 × 加入月数
  （平均標準報酬額は標準報酬月額の上限65万円・標準賞与額の年間上限573万円を反映）

#### P1-3　固定資産税が価格に対する一律の割合になっている

購入年と翌年以降の2つの入力値しかありません。実際は次のように動きます。

- **新築住宅の減額**：120㎡までの部分の固定資産税が、マンションは5年間、
  戸建ては3年間だけ1/2になる。**この減額が終わる年に大きく上がる**
- **土地の特例**：住宅用地は200㎡までは固定資産税の課税標準が1/6、
  都市計画税が1/3になる
- **建物の経年減価**：評価額が築年数とともに下がる

実測では、7,500万円のマンションで**1年目26万円→6年目34万円**（年11万円増）
→21年目18万円という動きになります。一律の割合では、この谷と山を見落とします。

土地と建物に分け、評価額・特例・新築減額・経年減価から計算する方式を
追加してください（既定は現在の簡易方式のままでよいです）。

なお建物の固定資産税評価額は**販売価格の3〜4割**が目安です
（販売価格には土地代・事業者の利益・広告費が含まれるため）。
5〜6割にすると税額が過大に出ます。

#### P1-4　相続税の見込みがない

この世帯は最終資産が1億円を超えるため、相続税が現実的な関心事になります。
次を追加してください。

- 一次相続（世帯主が亡くなる）と二次相続（配偶者が亡くなる）を分けて計算
- 基礎控除＝3,000万円＋600万円×法定相続人数
- 配偶者の税額軽減（1億6,000万円または法定相続分まで無税）
- 小規模宅地等の特例（居住用330㎡まで評価額80%減）
- 死亡保険金の非課税枠（500万円×法定相続人数）

**二次相続のほうが重くなること**（配偶者控除が使えず、基礎控除も
法定相続人が1人減るぶん600万円小さい）を示せると、
配偶者がどれだけ相続するかの判断材料になります。

実測では、遺産1億6,867万円で一次958万円＋二次535万円＝合計1,493万円。
配偶者の取得割合を50%から25%に変えると合計1,439万円に下がります。

検算には国税庁の速算例を使ってください（遺産2億円・配偶者と子2人の
相続税の総額は2,700万円、子2人のみなら3,340万円）。
