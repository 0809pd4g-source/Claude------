## 2. P0-1 住宅比較が手入力の年齢別保険表を上書きする

### 原因（こちらの作り込みミス）

v23で `planWithPreset()` を新設したとき、`defaults()` の行をそのまま持ってきました。

```js
if(p.living.insMode === "table") insGuideTable(p);
```

`defaults()`（世帯を新規に作る）では正しい。しかし `planWithPreset()` は
**「いまの家計はそのままで、住まいだけ」**と画面で約束しているコマンドの部品です。
**保険表は家計側のデータ**なので、触ってはいけませんでした。

**なぜ `COMPARE_ALLOWED` をすり抜けたか**：許可リストに `living.insuranceAfter` を入れており、
`living.insTable` の差分が「許可外」に数えられていませんでした。**許可リストが広すぎた。**
ご指摘のとおり、**葉パスで持つ**ように直しました。

### 直したこと

- `planWithPreset()` から `insGuideTable(p)` を削除。
- **`incomeH` / `retire` / `insuranceAfter` も当てないように**しました（住まいの軸ではないため）。
- 代わりに、購入⇄賃貸が変わるときだけ `meta.insReviewNeeded` を立て、
  **表は書き換えず「取得後の想定に合わせて見直してください」と画面で知らせます。**
- 許可リストを葉パスへ：

```js
loadAllPresets: ["meta.planName","meta.memo","meta.insReviewNeeded","meta.preset","house","estate"]
loadAllSavingPlans: [… ,"saving.plan","saving.adjustTable",
                        "saving.nisaMonthlyH","saving.nisaMonthlyW",
                        "saving.stockMonthlyH","saving.stockMonthlyW"]
```

### 実測（`insMode="table"` の独自表・44歳／50歳／65歳）

## 3. P0-2 詳細諸費用で借入が必要額に届かない

ご提示の閉じた式を採りました。

```js
function requiredLoanTotal(H){
  const detail = H.feeMode === "detail";
  const r = detail ? Number(H.feeLoanRate || 0) / 100 : 0;
  const cur = (H.loans||[]).reduce((s,l)=>s+Math.max(0,Number(l.amount)||0),0);
  const fixedFees = feeTotal(H) - (detail ? cur * r : 0);
  const numerator = Math.max(0, Number(H.price||0) + fixedFees
                                - Number(H.selfFund||0) - Number(H.gift||0));
  if(!Number.isFinite(r) || r < 0 || r >= 1) return numerator;   // 料率100%以上は式が成立しない
  return numerator / (1 - r);
}
```

複数借入では**丸めの残差を1本目に足して合計を必要額に合わせ**、
`fundingGap(H)` で恒等式を測れるようにしました。

## 4. P0-3 実入力の巨大数が `null` として成功保存される

## 10. 確認していただきたいこと

1. **P0 4件が利用者操作からのE2Eで解消しているか。**
2. **`requiredLoanTotal()` の式**。`feeLoanRate >= 100%` を「分母が0以下なので分子をそのまま返す」
   としていますが、**入力エラーとして拒否するほうがよいでしょうか。**
3. **許可リスト（葉パス）の妥当性。** `loadAllPresets` で `house` / `estate` を根で許しています。
   プロフィールのプリセットが物件全体を差し替えるためですが、**まだ広いでしょうか。**
4. **国保のその他課税所得**を「あなた」に寄せています（税の扱いと同じ）。
   パートナー側の副業所得があるとずれます。**分けるべきでしょうか。**
5. `readFinite()` が `""`（空欄）を0として扱います。**空欄と0を区別すべき欄はありますか。**
