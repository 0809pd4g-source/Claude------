## 手順と見るところ

### 1. 冷起動（いちばん大事）

開いた直後の画面で：

- [ ] 画面が**真っ白ではない**（左上に版番号だけ、という状態になっていない）
- [ ] 上部のメニュー（入力／保存プラン／診断／…）が見える
- [ ] **赤い警告が出ていない**（「保存された内容が読み取れませんでした」等）
- [ ] 横に指でなぞって、**画面が左右にずれない**

> v31で「初めて開いた人に赤いエラーが出る」不具合を出しています。ここが最重要です。

### 2. 最初の操作として「詳細設定」を開く

- [ ] 押した直後に画面が消えたり真っ白になったりしない
- [ ] 中の6つのタブ（世帯・収入・生活／住宅とローン／教育費／資産形成／ストレステスト／用語）を順に押して、**どれも表示される**
- [ ] どのタブでも横に**ずれない**

> V83の白画面は「冷起動して最初に詳細設定を押す」で出ました。

### 3. 入力してみる

「入力」タブで、ご自身の数字を入れてください（正確でなくてよいです）。

- [ ] 年齢・年収・生活費を入れると、**その場で結果が変わる**
- [ ] 数字を入れる欄で、**スマホのキーボードが数字用になる**
- [ ] 欄をタップしたとき、**画面が拡大されて戻らなくなることがない**
- [ ] 「住宅購入を検討する」をONにして物件価格を入れたとき、**表が画面幅からはみ出さない**（横スクロールできる枠に収まっている）

### 4. 診断を見る

- [ ] 「診断」タブに結果が出る
- [ ] まだ入力途中なら「**まだ判断には使わないでください**」等の断りが出る
- [ ] 断定的な結論だけが出て断りが見えない、という状態になっていない

### 5. 保存して開き直す（v35でいちばん直した所）

- [ ] プラン名を入れて「この入力を保存」→ 保存プランに**1件増える**
- [ ] もう1件、別の名前で保存 → **2件になる**
- [ ] **タブを閉じて、もう一度ファイルを開く**
- [ ] 開いた直後に**保存した2件がそのまま出ている**
- [ ] 赤い警告が出ていない

> ここが v29・v31・v34 で繰り返し直してきた所です。実機で1回通っていれば安心できます。

### 6. 印刷（任意）

- [ ] 「前提」タブの「レポートを印刷 / PDF保存」を押すと、印刷プレビューが出る
- [ ] 文字が切れていない
