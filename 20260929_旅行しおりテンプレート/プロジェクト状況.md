# プロジェクト状況：旅行しおりテンプレート

## 目的

エジプト・ギリシャ新婚旅行しおり（v18）を元に作成した、次の旅行計画に使える汎用テンプレートHTMLを管理する。

## 前提の整理

- 元ファイル：`20260901_新婚旅行しおり/02_output/20260901_新婚旅行しおり_v18.html`
- 旅行先固有のコンテンツを `[記入欄]` プレースホルダーに置き換え
- 全機能（タブ・チェックリスト・為替電卓・ダークモード・DAYジャンプ）はそのまま保持
- 単一HTMLファイル・オフライン動作

## 次の旅行での使い方

1. `02_output/20260929_旅行しおりテンプレート_v1.html` をコピー
2. 新プロジェクトフォルダ（`YYYYMMDD_○○旅行/`）として保存
3. `[記入欄]` をテキストエディタで一括検索して埋める
4. DAY カード・エリアガイド・フレーズタブを新しい旅行先に合わせて編集
5. 必要に応じてDAY数を増減（カードをコピー/削除）

## 残っているプレースホルダー（埋めるべき欄）

| セクション | 埋める内容 |
|---|---|
| タイトル・H1 | 旅行先名・旅行期間 |
| フライトサマリー | 全便の便名・時刻・空港コード |
| DAY 1〜N カード | 日付・滞在地・活動内容・ホテル名 |
| 日没カレンダー | 各日の日の出/日の入り時刻・エリア |
| エリアガイド | エリア名・スポット・レストラン・ホテル |
| 歴史タブ | 旅行先の歴史・文化の説明 |
| フレーズタブ | 現地語フレーズ・読み方 |
| 為替電卓 | 通貨コード（EGP/EUR/USD → 変更） |
| 持ち物タブ | 旅行先に合わせた細部の調整（大部分は流用可） |
