## ツール使用方法

```bash
# セクション一覧確認
cd 03_スクリプト
python manual_editor.py list

# セクション内容確認
python manual_editor.py show "会議参加・議事メモ作成"

# 文言置換（全体）
python manual_editor.py replace "旧担当者名" "新担当者名"

# 文言置換（特定セクション）
python manual_editor.py replace-in "開催連絡（金）" "旧文言" "新文言"

# 最終更新日を更新
python manual_editor.py set-date "中澤"

# セクション追加（JSONから）
python manual_editor.py add-section new_section.json
```

> **注意（Windows環境）**: スクリプト内の `TMP_DIR = Path("/tmp/manual_editor_work")` は
> Git Bash 経由では動作するが、PowerShell から直接実行する場合は
> `TMP_DIR = Path(os.environ["TEMP"]) / "manual_editor_work"` への変更が必要。
