# 運用上の約束

- 正式HTMLは常に1ファイルだけとする。
- 利用者に見える変更は、HTML内コメントだけでなく、このファイルへ記録する。
- 変動情報には、出典、情報基準日、確認日、次回確認日、確認トリガーを付ける。
- UIだけのパッチでは、構造化データを変更したか否かを明記する。
- 一部対応を「完了」と記録せず、残る制約を明示する。
- 過去の説明が実装状況を過大に表していた場合、次の履歴で訂正する。
